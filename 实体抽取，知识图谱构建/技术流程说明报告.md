# 实体抽取与知识图谱构建 — 技术流程说明报告

> 数据来源：`数据集合并/outputs/merged_dataset.csv`（2876 个唯一专利）+ `merged_patent_info.csv`（31899 条专利元数据）
> 生成日期：2026-08-07

## 一、研究目标

从合并数据集中提取专利实体与关系，构建 BCI（脑机接口）专利领域的知识图谱。每个专利抽取 9 类实体关系：

| 关系模式 | 实体类型 | 抽取方式 |
|---|---|---|
| 专利 —解决→ 技术问题 | 技术问题 | LLM 摘要抽取 |
| 专利 —应用于→ 应用场景 | 应用场景 | LLM 摘要抽取 |
| 专利 —采用→ 技术方法 | 技术方法 | LLM 摘要抽取 |
| 技术方法 —处理→ 生物信号类型 | 生物信号类型 | LLM 摘要抽取（方法-信号配对） |
| 专利 —基于→ 技术原理 | 技术原理 | LLM 摘要抽取 |
| 专利 —包括→ 核心部件 | 核心部件 | LLM 摘要抽取 |
| 专利 —属于→ 技术主题 | 技术主题 | **原始信息**（主IPC分类号大类映射） |
| 专利 —公开国家→ 国家 | 国家 | **原始信息**（country 字段） |
| 专利 —公开年→ 年份 | 年份 | **原始信息**（app_year 字段） |

其中**技术主题、公开国家、公开年份**均取自原始元数据而非 LLM 推断，保证图谱中这三类信息的可溯源性；LLM 仅负责从摘要中抽取其余 6 类文本语义实体。

## 二、数据准备

1. **唯一化**：`merged_dataset.csv` 3009 行 → 按公开号去重 → **2876 个唯一专利**（主路径专利跨时期/跨路径重复出现，如 US20090036756A1 出现在 11 条路径，按专利唯一化处理）
2. **元数据合并**：与 `merged_patent_info.csv` 按规范化公开号（去连字符、大写）左连接，取得 `country`（公开国家）、`app_year`（公开年）、`主IPC分类号`、`IPC分类号`、`公开日`、双语标题
3. **摘要确定**：优先使用 merged_dataset 中已有中文摘要，缺失时回查元数据库中文/英文摘要

## 三、LLM 批量实体抽取

### 3.1 调用架构（双提供商兜底）

| 提供商 | 模型 | 费用 | 角色 |
|---|---|---|---|
| 智谱 GLM | glm-4.7-flash | 免费 | 主调用（优先） |
| DeepSeek | deepseek-v4-flash | 付费 | 兜底（GLM 429 限流重试耗尽后回退） |

- **并发**：4 线程；**重试**：GLM 6 次指数退避（基数 2 秒），DeepSeek 兜底 2 次
- **省时设置**：两模型均启用 `thinking: {"type": "disabled"}` 关闭推理过程
- **任务格式**：JSONL 逐条（id=公开号，prompt=抽取 schema + 标题 + 摘要）
- **输出**：JSONL 实时落盘，`provider` 字段标明实际调用方；失败任务 `ok:false` 可用 `--resume` 补跑
- 抽取 schema 要求：每类实体 1~5 个，优先使用摘要原词/标准术语，未提及的类输出空数组；同时输出"方法-信号"配对

### 3.2 运行参数与规模

- 任务总数：**2863**（有摘要唯一专利）
- 参数：`--max-tokens 1500 --temperature 0.2 --retries 6 --retry-base 2`
- 实测样本（30 条）：GLM 16 条 + DeepSeek 兜底 14 条，**30/30 成功，JSON 解析率 100%**

### 3.3 抽取结果统计（全量）

| 指标 | 数值 |
|---|---|
| 成功 / 失败 | **2863 / 0**（100% 成功，JSON 解析率 100%） |
| provider 分布 | GLM 118 条 + DeepSeek 2745 条 |
| 执行方式 | 首轮 GLM 主调+DeepSeek 兜底（并发 4，受 GLM 429 限流拖累）；全量改用 `--provider deepseek` 直连（并发 10），2576 条 **534 秒**完成、0 失败 |
| 总耗时 | 约 22 分钟（含早期限流期） |
| 数据落盘 | `entity_results.jsonl` 2863 行完整保留，全部可复核 |

## 五、实体消歧与主题细化（2026-08-07 增补）

### 5.1 实体消歧（规则归一化 + LLM 语义聚类 + 二次审核）

| 阶段 | 方法 | 结果 |
|---|---|---|
| 规则归一化 | 全半角/大小写/括号统一（仅机械层面） | 53978 次出现 → 24216 个唯一名 |
| LLM 语义聚类 | 每批 50 个实体名，要求只输出同义组（EEG↔脑电信号），DeepSeek 直连 488 批 + 2 批重试 | 4195 个合并组，合并减少 7131 |
| 二次审核 | 对 n≥5 的 119 个大组逐组审核（同义保留/子类型拆出） | **拆分 829 个误并成员**（77% 大组成员），保留 228 个 |

**消歧效果**：语义实体节点 24222 → **19956**（减少 4266，-17.6%）；生物信号类型减少最多（-24%）。
典型误并及修正："参考电极"→"电极"（子类型，拆出）、"阿尔法波"→"脑电波"（频段概念，拆出）、"eeg, eog"→"脑电信号"（组合概念，拆出）。

**质量保证**：映射表 `canonical_map.csv` 全量保留（25564 条 alias→canonical，含来源频次）；LLM 改写的成员名（563 条）一律丢弃不合并；合并只影响 LLM 抽取的 6 类语义实体，原始信息（技术主题/国家/年份）不受影响。

## 六、质量与可溯源性

- **公开国家/公开年份不依赖 LLM**：直接从元数据提取，杜绝模型幻觉；**技术主题归属**同样由主IPC分类号规则提取（无 LLM 判断），仅主题**中文名**由 LLM 生成（`ipc_subtopic_map.csv` 可复核）
- **LLM 输出可复核**：原始 JSONL 完整保留，解析失败单独列清单（见 parse_failures.csv）
- **图谱可回溯**：每条关系带来源专利公开号
- **13 条无摘要专利**单独说明（见第二节），不计入 LLM 抽取范围

## 七、局限与后续

1. 免费模型限流严重（实测并发 6 时失败率 >60%），双提供商 + 降并发（4）+ 断点续跑解决；DeepSeek 直连（并发 10）无此问题
2. 生物信号类型空占比约 60%——部分专利（如电极材料、数据处理算法类）确实不涉及信号类型，属正常分布
3. 实体消歧批次输出上限问题：每批 100+ 实体名时分组 JSON 易超模型输出上限被截断，需降至 50 并配 8000 max-tokens（已解决）
4. 实体消歧的 LLM 聚类存在粒度误并倾向（子类型并入泛称），已通过 n≥5 大组二次审核拆回（829 条）；小组成员（n<5）未逐组审核，存在残余误并风险
5. 后续可做：图谱可视化（Gephi/Neo4j）、与技术发展路径关联分析、消歧后实体共现/网络指标分析
