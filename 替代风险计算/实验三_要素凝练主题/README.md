# 实验三：按知识要素凝练主题配对（"文档要求版"）

> 严格按《替代风险计算研究方案.md》第三步执行。本实验用 LLM 从专利的技术要素出发**凝练出技术主题**（而非用 IPC 分类号或主路径），再按文档口径做替代风险计算。

## 完整过程（五步，每一步的输入输出都有真实样例）

### 第 1 步：LLM 批量打技术主题标签（2493 条专利 → 2493 个标签）

**输入**：每条专利的（技术方法、技术问题、应用场景）——这些要素来自知识图谱的实体抽取。为节省调用次数与费用，**每批 10 条专利拼接成一个 LLM 调用**（共 250 次调用，而非 2493 次）。

实际发给 LLM 的内容长这样（公开号|技术方法|技术问题|应用场景，每条一行）：

```
US20040102828A1|刺激参数控制、植入颅内电极|调节电极长度以改变远端接触表面相对于脑表面的接触力|神经刺激、脑电图分析
US20050021105A1|对脑进行电刺激、将刺激部位神经元的静止膜电位增加到亚阈值水平、诱导神经可塑性|增强或诱导神经活性的持久改变、治疗脑损伤|疼痛控制、脑损伤治疗、认知增强
```

**输出**（deepseek-v4-flash，JSON 格式，每条专利一个 ≤12 字标签）：

```json
{"tags": {"US6873872B2": "定向电场神经调控", "US20090018609A1": "闭环神经调制系统",
          "CN111200967A": "高频振荡刺激检测", "US11583678B2": "神经退行性疾病检测", ...}}
```

**结果**：250 批调用 **全部成功**，2493/2493 条专利解析出标签（解析率 100%），共 **2152 个唯一标签**（如"实时脑电信号采集""闭环神经调制系统""脑电情绪识别"）。其中有 13 条专利因 LLM 回显的公开号乱码（如 US11132625B1→US111326325B1）无法与路由表匹配，未进任何主题（实际入主题 2480/2493）。

### 第 2 步：LLM 归并同义标签（2152 个 → 1125 个代表标签）

2152 个标签里有很多同义异形（如"实时脑电信号采集"与"干电极脑电采集"都描述脑电采集）。把标签按每批 50 个发给 LLM，让它找出同义组：

**输出**（每组是同义标签列表）：

```json
{"groups": [
  ["实时脑电信号采集", "干电极脑电采集", "干电极脑电采集装置"],
  ["干式EEG电极结构", "干式脑电电极结构", "干电极脑电帽"],
  ["实时多模态情绪识别", "对比学习情绪识别"], ...]}
```

**结果**：44 批调用，归并出 **946 个同义组**（组内平均 2.1 个标签）+ **179 个独组**（没有同义的标签各自成组），得到 **1125 个代表标签**。

### 第 3 步：嵌入聚类凝练成 45 个技术主题（1125 个 → 45 个）

为什么需要聚类：实测发现 LLM 归并**只做细粒度同义归并**（"实时脑电信号采集"≈"干电极脑电采集"），跨批的同义标签无法相遇，收敛后仍有约 1125 个标签，达不到 10~60 个主题的目标粒度。

因此对 1125 个代表标签做**嵌入聚类**：先用 bge 嵌入模型把每个标签变成向量，再用 Ward 层次聚类（确定性算法，可复现）分成 **45 簇**——每一簇就是一个候选主题。选择 Ward 是因为实测它的簇大小均衡（最大簇占 4.8%），不会出现一个巨簇吞掉所有标签。

### 第 4 步：LLM 给每个主题命名（45 簇 → 45 个主题名）

把每个簇的成员标签列表发给 LLM，让它起一个能概括全组的主题名：

**输入**（簇的成员标签）：

```
主题 C0：
- 单通道脑电情感识别
- 对比学习情绪识别
- 脑电情感识别
- 脑电情绪识别解锁
- 脑电熵特征情感识别
...
```

**输出**：`{"names": {"C40": "脑电虚拟现实交互", "C41": "脑电电极采集装置", "C42": "脑电听觉调控降噪", ...}}`

**结果**：45/45 主题全部命名成功。最终主题名示例：C0=脑电情绪识别分析、C31=植入式神经接口系统、C8=神经刺激监测装置、C35=神经刺激参数优化、C26=神经刺激电极装置。每主题含 12~139 条专利。

### 第 5 步：主题对 + 双前提 + 硬阈值计算替代风险（45 主题 → 1980 有序对）

45 个主题两两配对成有序对（"国外 Y 替代 国内 X"，45×44=1980 对）。按文档 3.3 口径，每对过两道门槛：

1. **替代候选双前提**：两个主题须**解决同一类问题**（知识图谱"问题"实体的集合相似度≥0.5）且**原理明显不同**（H≥0.3）
2. **硬阈值**：F≥0.6、C≥0.5、H≥0.3 **全过**才计算综合得分与风险 R；未过前提/未达阈值的对留表带标记、不参与排名

风险公式 R = S × (M + V) ÷ 2 与实验一/二完全相同（公式表见总 README）。

达标率 80%（1580/1980）的原因：45 个主题由同一 BCI 领域凝练而来，功能/场景普遍相似（F/C 均值≈0.65），原理差异普遍满足 H≥0.3（仅 24 对不足）——F 是实际主要门槛；主题粒度下 H 分布拉开到 0.279~0.493，硬阈值判定稳健（不像实验二 6 对挤在 0.288~0.303 临界窄带）。

## 实验结论

1. **风险最高的替代关系**："国外 C8 神经刺激监测装置 → 国内 C31 植入式神经接口系统"（R=0.508），其性质是**"国外强势、国内空白"**——被替代侧（C31）国内专利为 0、替代侧核心技术 99.6% 在国外（K_B=0.996）、中国高价值专利为零（A_B=0.0）。Top-5 对中 4 对的被替代侧国内专利为 0 或仅个位数。
2. **风险排序由"替代成熟度"（M）主导**：全部 1580 个达标对的"可替代性 S"集中在 0.508~0.613（跨度仅 0.105），而 M 在 0.376~0.704（跨度 0.328）；风险排序前 50 对中，R 与 M 的相关系数 0.42、与 S 仅 0.18——**头部的风险差异主要来自"国外路线增长更快、主路径地位上升"**，与实验二结论一致。
3. **文档口径（双前提+硬阈值）在主题粒度下是稳健筛选器**：45 个主题由同一 BCI 领域凝练而来，功能/场景普遍相似、原理差异普遍达标，所以 80% 的主题对能通过门槛；且 H 分布拉开到 0.279~0.493，达标判定不依赖临界巧合（对照实验二 6 对原理差异挤在 0.288~0.303 窄带、唯一达标对仅超阈值 0.003 的临界情形）。
4. **与前两份实验结论一致**：无论按 IPC 主题（实验一）、主路径路线（实验二）还是知识要素凝练主题（实验三）划分技术路线，风险靠前者都是"国外主导、国内缺位"；且剔除无关专利前后结论不变——**结论是稳的，不随主题划分方式改变**。

**结论解读提醒**（写论文时请注意）：

- R 值域窄（0.327~0.508、中位 0.414），R>0.45 的只有 87 对（5.5%）——"高替代风险"的对很少，建议表述为"排序前 5% 的对相对风险最高"，而非"R=0.5 代表高风险"。
- "缺位型"是**头部现象**：1580 达标对中被替代侧国内专利为 0 的仅 19 对（1%），但它们高度集中在风险排序前列（Top-10 占 7 对）——"风险靠前者均为缺位型"准确，但不要扩展成"所有达标对都是缺位型"。
- 统计基础良好：95% 的达标对被替代侧国内专利 ≥3 条、仅 5% 带"样本不足"标记——实验三的统计可靠性高于实验二（6 对中大多样本不足）。

## 复现

```powershell
cd 替代风险计算   # 项目根
python 共用/scripts/filter_relevance.py    # 前置：BCI 相关性判定（需 DEEPSEEK_API_KEY）
python 实验三_要素凝练主题/scripts/theme_discovery.py  # 第 1-4 步：LLM 标签+归并+聚类+命名（需 DEEPSEEK_API_KEY）
python 实验三_要素凝练主题/scripts/theme_pairs.py      # 第 5 步前置：主题版专利表
# config.json 的 input_suffix = "_theme"
python 共用/scripts/run_all.py             # 第 5 步：主题对门槛判定 + 指标计算
python 共用/scripts/generate_report.py     # 报告
```

LLM 调用约 250 次标签 + 44 次归并 + 5 次命名（批量拼接，费用低）；断点续跑用 batch_llm 的 --resume。重跑产物默认落在根 `outputs/`，本目录 `outputs/` 为已归档副本。
