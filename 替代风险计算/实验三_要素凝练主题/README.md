# 实验三：按知识要素凝练主题配对（"文档要求版"）

## 怎么做

严格按《替代风险计算研究方案.md》3.3 口径：LLM 逐条给 2493 条专利打技术主题标签（解析率 100%，13 条因 LLM 回显公开号乱码未入主题）→ 归并聚类成 45 个凝练主题（如 C31 植入式神经接口系统、C8 神经刺激监测装置）→ 两两配成有序对（45×44=1980 对，"国外 Y 替代国内 X"，主题码 X→Y）。与实验一/二的关键区别是两道门槛（公式表见总 README）：

1. **替代候选双前提**：问题实体集合相似度 ≥0.5（解决同一类问题）且 H≥0.3（原理明显不同）；
2. **硬阈值**：F≥0.6 / C≥0.5 / H≥0.3 全过才计算综合得分与排名；未过前提/未达阈值的对留表带标记、不参与排名。

## 结果

| 总表文件 | 主题 | 主题对 | 未过双前提 | 未达硬阈值 | 无高价值专利 | 达标参与排名 |
|---|---|---|---|---|---|---|
| `outputs/替代风险指标总表_theme.csv` | 45 | 1980 | 30 | 230 | 140 | 1580 |

风险最高：C31→C8（国外 C8 神经刺激监测装置 替代 国内 C31 植入式神经接口系统）R=0.508；其后 C31→C26（0.491）、C35→C8（0.490）。
Top1 画像：K_B=0.996、A_B=0.0、V_B=0.998——替代侧核心技术 95% 以上在国外、被替代侧国内高价值专利为零，与前两份实验结论一致：**国外主导、国内缺位**。
