## 完整过程（五步，每一步的输入输出都有真实样例）

### 第 1 步：LLM 批量打技术主题标签（2493 条专利 → 2493 个标签）

**输入**：**拓展后研究数据集**（主路径专利 + 语义相似拓展专利，共 2876 条）中进入知识图谱、且通过 BCI 相关性过滤的 **2493 条专利**。注意：不是"主路径节点"本身（每窗口主路径节点仅 21~43 个，样本过小），而是整个拓展后数据集的相关子集。每条专利输入（技术方法、技术问题、应用场景）三类要素——来自知识图谱的"采用 / 解决 / 应用于"实体抽取；技术原理不参与打标签（原理留给第 5 步的 H_AB 差异度计算）。为节省调用次数与费用，**每批 10 条专利拼接成一个 LLM 调用**（共 250 次调用，而非 2493 次）。

实际发给 LLM 的内容长这样（公开号|技术方法|技术问题|应用场景，每条一行）：

```
US20040102828A1|刺激参数控制、植入颅内电极|调节电极长度以改变远端接触表面相对于脑表面的接触力|神经刺激、脑电图分析
US20050021105A1|对脑进行电刺激、将刺激部位神经元的静止膜电位增加到亚阈值水平、诱导神经可塑性|增强或诱导神经活性的持久改变、治疗脑损伤|疼痛控制、脑损伤治疗、认知增强
```

**输出**（deepseek-v4-flash，JSON 格式，每条专利一个 ≤12 字标签）：

```json
{"tags": {"US6873872B2": "定向电场神经调控", "US20090018609A1": "闭环神经调制系统",
          "CN111200967A": "高频振荡刺激检测", "US11583678B2": "神经退行性疾病检测", ...}}
```

**结果**：250 批调用 **全部成功**，2493/2493 条专利解析出标签（解析率 100%），共 **2152 个唯一标签**（如"实时脑电信号采集""闭环神经调制系统""脑电情绪识别"）。其中有 13 条专利因 LLM 回显的公开号乱码（如 US11132625B1→US111326325B1）无法与路由表匹配，未进任何主题（实际入主题 2480/2493）。

### 第 2 步：LLM 归并同义标签（2152 个 → 1125 个代表标签）

2152 个标签里有很多同义异形（如"实时脑电信号采集"与"干电极脑电采集"都描述脑电采集）。把标签按每批 50 个发给 LLM，让它找出同义组：

**输出**（每组是同义标签列表）：

```json
{"groups": [
  ["实时脑电信号采集", "干电极脑电采集", "干电极脑电采集装置"],
  ["干式EEG电极结构", "干式脑电电极结构", "干电极脑电帽"],
  ["实时多模态情绪识别", "对比学习情绪识别"], ...]}
```

**结果**：44 批调用，归并出 **946 个同义组**（组内平均 2.1 个标签）+ **179 个独组**（没有同义的标签各自成组），得到 **1125 个代表标签**。

### 第 3 步：嵌入聚类凝练成 45 个技术主题（1125 个 → 45 个）

为什么需要聚类：实测发现 LLM 归并**只做细粒度同义归并**（"实时脑电信号采集"≈"干电极脑电采集"），跨批的同义标签无法相遇，收敛后仍有约 1125 个标签，达不到 10~60 个主题的目标粒度。

因此对 1125 个代表标签做**嵌入聚类**：先用 bge 嵌入模型把每个标签变成向量，再用 Ward 层次聚类（确定性算法，可复现）分成 **45 簇**——每一簇就是一个候选主题。选择 Ward 是因为实测它的簇大小均衡（最大簇占 4.8%），不会出现一个巨簇吞掉所有标签。

### 第 4 步：LLM 给每个主题命名（45 簇 → 45 个主题名）

把每个簇的成员标签列表发给 LLM，让它起一个能概括全组的主题名：

**输入**（簇的成员标签）：

```
主题 C0：
- 单通道脑电情感识别
- 对比学习情绪识别
- 脑电情感识别
- 脑电情绪识别解锁
- 脑电熵特征情感识别
...
```

**输出**：`{"names": {"C40": "脑电虚拟现实交互", "C41": "脑电电极采集装置", "C42": "脑电听觉调控降噪", ...}}`

**结果**：45/45 主题全部命名成功。最终主题名示例：C0=脑电情绪识别分析、C31=植入式神经接口系统、C8=神经刺激监测装置、C35=神经刺激参数优化、C26=神经刺激电极装置。每主题含 12~139 条专利。

> 已知限制：命名调用每个主题**最多发送前 30 个成员标签**（45 簇中 31 簇成员标签数超过 30、最多 115，命名所见为成员子集）。主题名由可见成员归纳，个别大簇的名称可能未覆盖全部成员；如需更全可在 `build_name_tasks` 中调大发送上限后重跑第 4 步（聚类结果确定、可复现）。

### 第 5 步：主题对 + 双前提 + 硬阈值计算替代风险（45 主题 → 1980 有序对）

45 个主题两两配对成有序对（"国外 Y 替代 国内 X"，45×44=1980 对）。按文档 3.3 口径，每对过两道门槛：

1. **替代候选双前提**：两个主题须**解决同一类问题**（知识图谱"问题"实体的集合相似度≥0.5）且**原理明显不同**（H≥0.3）
2. **硬阈值**：F≥0.6、C≥0.5、H≥0.3 **全过**才计算综合得分与风险 R；未过前提/未达阈值的对留表带标记、不参与排名

风险公式 R = S × (M + V) ÷ 2 与实验一/二完全相同（公式表见总 README）。

## 实验结论

1. **风险最高的替代关系**："国外 C8 神经刺激监测装置 → 国内 C31 植入式神经接口系统"（R=0.508），其性质是**"国外强势、国内空白"**——被替代侧（C31）国内专利为 0、替代侧核心技术 99.6% 在国外（K_B=0.996）、中国高价值专利为零（A_B=0.0）。Top-5 对中 4 对的被替代侧国内专利为 0 或仅个位数。
2. **风险排序由"替代成熟度"（M）主导（主要体现在风险头部）**：全部 1580 个达标对的"可替代性 S"集中在 0.508~0.613（跨度仅 0.105），而 M 在 0.376~0.704（跨度 0.328）；风险排序前 50 对中，R 与 M 的 Pearson 相关系数 0.54、与 S 仅 0.29（Spearman 0.60 / 0.20，同向）——**头部的风险差异主要来自"国外路线增长更快、主路径地位上升"**，与实验二结论一致。注意：全量 1580 对上 R~M=0.46、R~S=0.44，M 的主导作用收窄为头部效应，全量下 S 与 M 的贡献接近。
3. **文档口径（双前提+硬阈值）在主题粒度下是稳健筛选器**：45 个主题由同一 BCI 领域凝练而来，功能/场景普遍相似、原理差异普遍达标，所以 80% 的主题对能通过门槛；且 H 分布拉开到 0.279~0.493，达标判定不依赖临界巧合（对照实验二 6 对原理差异挤在 0.288~0.303 窄带、唯一达标对仅超阈值 0.003 的临界情形）。
4. **与前两份实验结论一致**：无论按 IPC 主题（实验一）、主路径路线（实验二）还是知识要素凝练主题（实验三）划分技术路线，风险靠前者都是"国外主导、国内缺位"；且剔除无关专利前后结论不变——**结论是稳的，不随主题划分方式改变**。

**结论解读提醒**（写论文时请注意）：

- **高风险线定档：R≥0.45（用户定档，87 对、占达标对 5.5%，即风险排序前 87 对）**。R 值域 0.327~0.508、中位 0.414，"R=0.5 代表高风险"并不成立（R 最高仅 0.508）；0.45 是相对高风险线——论文中"高风险替代对"即指这 87 对（风险排序前 5.5%）。
- **为什么 R 数值偏低：乘法压缩效应的必然结果（写论文时的标准解释）**。R = S × (M+V)/2 是两个 [0,1] 因子的乘积，乘积必然 ≤ 任一因子：本数据 S 全部挤在 0.508~0.613（嵌入相似度宽松但集中、上限 0.613），(M+V)/2 均值 0.73，二者相乘后 R 均值仅 0.41。即**只要 S 因子不高，另一因子即使接近满分，R 也封顶**——乘法表达的语义是"可替代性与替代势能/暴露度同时成立"的强约束，绝对水平低是公式结构所致，**排序与相对差异才是核心结论**；若未来想抬升数值，正确方向是提高 S 因子上限（如把 H 改为集合重合度 Jaccard 补集，R 最高约 0.67），而不是对 R 做事后归一化（那只改变展示、不改变信息）。
- "缺位型"是**头部现象**：1580 达标对中被替代侧国内专利为 0 的仅 19 对（1%），但它们高度集中在风险排序前列（Top-10 占 7 对）——"风险靠前者均为缺位型"准确，但不要扩展成"所有达标对都是缺位型"。
- 统计基础良好：95% 的达标对被替代侧国内专利 ≥3 条、仅 5% 带"样本不足"标记——实验三的统计可靠性高于实验二（6 对中大多样本不足）。

## 指标总表（CSV）字段说明

`outputs/替代风险指标总表_theme.csv` 共 1980 行（45 主题的有序对，每对一行）。配对方向记作 **X→Y**：X=被替代侧（国内路线 A），Y=替代侧（国外路线 B），即"国外 Y 替代 国内 X"。各列含义：

| 列名 | 含义 | 计算口径 |
|---|---|---|
| 主题码 | 配对方向 | `X→Y`，X≠Y，共 45×44=1980 对 |
| 主题名 | X 主题名→Y 主题名 | 主题名见表"45 个技术主题明细" |
| n_国内 | X 主题内中国专利数 | 被替代侧 A 的专利数 |
| n_国外 | Y 主题内国外专利数 | 替代侧 B 的国外专利数 |
| F_AB | 功能相似度 | X、Y 两主题"采用"（技术方法）实体集合的嵌入对称最佳匹配相似度（bge-small-zh，值域 0~1） |
| C_AB | 场景相似度 | 同上，"应用于"（应用场景）实体集合 |
| H_AB | 技术原理差异度 | 1 − "基于"（技术原理）实体集合嵌入相似度；越大表示原理差异越大 |
| S_AB | 技术可替代性 | (F_AB + C_AB + H_AB) ÷ 3（w1=w2=w3=1） |
| F_J / C_J / H_J | Jaccard 对照列 | 同一指标用 Jaccard 集合相似度计算的结果（嵌入版偏宽松、Jaccard 版偏严格，双列供对比，实际门槛判定用嵌入版 F/C/H） |
| g_A / g_B | 增长斜率 | A 侧国内（B 侧国外）专利 ln(1+累计数) 对 6 个时间窗口的线性回归斜率；累计按公开年 ≤ 窗口末计 |
| G_AB | 相对增长优势 | sigmoid(g_B − g_A)（k=2）；国外路线增长越快越接近 1 |
| p_A初期 / p_A末期 | A 侧主路径占比 | pre2000（初期）与 2000-2026（末期）窗口内，主路径节点中 A 侧专利占比 |
| p_B初期 / p_B末期 | B 侧主路径占比 | 同上，B 侧 |
| Δp_A / Δp_B | 主路径占比变化 | p_末期 − p_初期 |
| T_AB | 主路径地位转移 | sigmoid(Δp_B − Δp_A)（k=2）；"国外占比升、国内占比降"越明显越接近 1 |
| M_AB | 替代势能（替代成熟度） | (G_AB + T_AB) ÷ 2 |
| K_B | 国外核心专利控制度 | Y 主题全集（含国内）内按被引权重（in_degree+1）加权的国外专利占比 |
| A_B | 国内自主能力 | Y 主题高价值专利（全库被引 top10%，≥44 次）中中国专利占比 |
| V_B | 国内安全暴露度 | (K_B + 1 − A_B) ÷ 2；Y 主题无高价值专利时为空 |
| R_AB | 最终替代风险 | S_AB × (M_AB + V_B) ÷ 2；未过门槛或 V 为空时为空（不参与排名） |
| 标记 | 状态标记（可叠加） | 未过前提（问题相似度<0.5 或 H<0.3）／未达阈值（F<0.6 或 C<0.5 或 H<0.3）／样本不足（任一侧专利<3）／无高价值专利 |
| 问题相似度 | 前提①"解决同一类问题"的量化值 | 两主题"解决"（技术问题）实体集合的嵌入对称最佳匹配相似度；≥0.5 且 H≥0.3 才进入硬阈值判定 |
| 风险排名 | R_AB 降序排名 | 仅达标对（R_AB 非空，共 1580 对）参与；其余为空。**高风险线：R≥0.45（前 87 对，占 5.5%）** |
