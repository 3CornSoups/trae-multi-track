# 实验一：按 IPC 主题排查（"细查版"）

> 把研究数据集按专利自带的 IPC 分类号分成 147 个技术主题，逐主题比较中国专利与国外专利，计算"国外技术替代国内技术"的风险。

## 完整过程（四步）

### 第 1 步：数据准备（每个专利 → 主题/国别/年份/实体集合）

从知识图谱边表构建每专利一行（`prepare.py`）：专利的 IPC 主题（主IPC 大组，如 A61B5 身体诊断测量、A61N1 电疗器械）、公开国家（CN=国内）、公开年、被引次数（来自引文网络），以及三类知识要素实体集合——**功能**（"采用"关系）、**场景**（"应用于"关系）、**原理**（"基于"关系），实体为 LLM 从摘要抽取并消歧后的规范名（如"植入颅内电极""脑电信号采集"）。

### 第 2 步：实体嵌入相似度（BGE 嵌入 + 对称最佳匹配）

把全部实体名用 bge-small-zh-v1.5 编码成向量（`embed_similarity.py`），之后任意两个实体集合的相似度 = **对称最佳匹配**：每个实体找对方集合中最相似的实体取平均（½[mean_a max_b cos + mean_b max_a cos]）。用嵌入而非字符串比对，是因为同义异形（如"RF信号传输能量" vs "RF能量传输"）在字符串层面零交集——实测 Jaccard 口径下 92% 主题零交集，嵌入口径下凡双方有实体的主题全部可计算。

### 第 3 步：BCI 相关性过滤（LLM 逐条判定，过滤版）

研究数据集由语义匹配扩展而来，混入与脑机接口无关的专利（如位置广告）。先用 LLM 逐条判定"是否属于 BCI 领域或其直接应用"（`filter_relevance.py`，deepseek-v4-flash，共 2969 次调用，100% 成功）：

**输入**（每条专利的标题+摘要）：

```
专利公开号：US20040102828A1
标题：使用颅内电极用于神经刺激和/或脑电描记术的方法和系统
摘要：本发明的方面涉及颅内电极和用于植入和使用颅内电极的方法。…
请判定该专利是否属于脑机接口领域。
```

**输出**（JSON，含类别与理由）：

```json
{"relevant": true, "category": "核心", "reason": "涉及颅内电刺激调控神经可塑性，属BCI神经调控核心"}
{"relevant": false, "category": "无关", "reason": "神经刺激装置未涉及脑信号采集或解码"}
```

判定口径：涉及脑信号采集/解码/处理/神经调控，或直接消费脑信号的系统（含神经营销、BCI 教育等边缘应用）为相关；仅位置广告、一般医疗器械、纯算法工具为无关。

**结果**：相关 2582（87%）/ 无关 387（13%），剔除无关专利 370 条，保留 2493 条（CN 660）；147 个主题中 14 个因专利全部无关而整体退出。

### 第 4 步：指标计算与排名（run_all.py）

对每个主题：中国专利（国内筐）与国外专利（国外筐）比三件事（公式详见总 README）：

1. **S 可替代性**：功能/场景相似度（第 2 步的嵌入相似度）+ 原理差异度 H=1−原理相似度，加权合成
2. **M 替代成熟度**：国外筐专利增速是否快于国内（6 个时间窗口 ln(1+N) 对数增长斜率之差）+ 国外筐在技术主干道（主路径）上的占比是否上升
3. **V 安全暴露度**：核心专利被国外掌控比例（按被引加权）+ 中国高价值专利（被引前 10%，≥44 次）占比的缺口

**R = S × (M + V) ÷ 2**，按 R 降序排名（软阈值口径：F≥0.6/C≥0.5/H≥0.3 为"达标"参考标记，不影响排名）。

## 结果

| 版本 | 总表文件 | 主题数 | 参与排名 | 无"未达标"标记 | 风险最高（Top1） |
|---|---|---|---|---|---|
| IPC 全量 | `outputs/替代风险指标总表.csv` | 147 | 46 | 10 | G06Q30 商业交易系统（R=0.457） |
| IPC 过滤后 | `outputs/替代风险指标总表_filtered.csv` | 133 | 38 | 9 | G06Q30 商业交易系统（R=0.463） |

过滤版 Top-3：G06Q30 商业交易系统（0.463）、A61N2 磁疗器械（0.430）、G06F17 数据处理（0.429）。Top1 画像：K_B=0.936（国外掌控 92%+）、A_B=0.0（中国高价值专利为零）、V_B=0.968。

## 实验结论

1. **风险最高的是 G06Q30 商业交易系统（神经营销）**：其保留专利均为脑电广告/神经营销类边缘应用（属 BCI 纳入口径），国外专利掌控 92% 以上、中国高价值专利为零。
2. **风险性质是"缺位"而非"被挤"**：风险靠前主题的共同特征是国外专利占比 92%+、国内高价值专利≈0——国内在这些主题上没有布局，而非已有技术被挤掉。
3. **过滤无关专利前后结论不变**（Top1 同为 G06Q30，0.457→0.463）——风险信号不是数据污染造成的假象。

## 复现

```powershell
cd 替代风险计算   # 项目根（所有脚本按 ROOT=项目根 解析路径）
python 共用/scripts/prepare.py           # 第 1 步（需本地原始数据，见仓库根 数据清单.md）
python 共用/scripts/embed_similarity.py  # 第 2 步（bge-small-zh-v1.5，离线用本地 HF 缓存）
python 共用/scripts/filter_relevance.py  # 第 3 步（需 DEEPSEEK_API_KEY；仅过滤版需要）
# config.json 的 input_suffix："" = 全量；"_filtered" = 过滤
python 共用/scripts/run_all.py           # 第 4 步
python 共用/scripts/generate_report.py   # 报告
```

重跑产物默认落在根 `outputs/`，本目录 `outputs/` 为已归档副本（含 .bak 历史版本）。
