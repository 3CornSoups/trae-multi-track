# 实验一：按 IPC 主题排查（"细查版"）

## 怎么做

研究数据集 2863 条 BCI 专利按专利自带 IPC 大组分 147 个技术主题；每个主题把**中国专利**与**国外专利**各装一筐，用与总 README 相同的公式（R = S × (M+V) ÷ 2）比三件事：

1. 两筐专利做的事像不像（F/C 嵌入语义相似度 + H=1−原理相似度）；
2. 国外这筐增长快不快、主干道地位涨没涨（6 窗口对数增长斜率 + 主路径占比）；
3. 被替代了疼不疼（核心技术被国外掌控比例 K、中国高价值专利占比 A，高价值=被引前 10%，≥44 次）。

软阈值 F≥0.6 / C≥0.5 / H≥0.3 仅作参考标记（"未达标"），不影响排名——有 R 即参与排名。

## 结果

| 版本 | 总表文件 | 主题数 | 参与排名 | 无"未达标"标记 | 风险最高（Top1） |
|---|---|---|---|---|---|
| IPC 全量 | `outputs/替代风险指标总表.csv` | 147 | 46 | 10 | G06Q30 商业交易系统（R=0.457） |
| IPC 过滤后 | `outputs/替代风险指标总表_filtered.csv` | 133 | 38 | 9 | G06Q30 商业交易系统（R=0.463） |

过滤版口径：AI 逐条判定 2969 条（100% 成功，相关 2582 / 无关 387）剔除 370 条无关专利后重算，专利 2863→2493、主题 147→133。

过滤版 Top-3：G06Q30 商业交易系统（0.463）、A61N2 磁疗器械（0.430）、G06F17 数据处理（0.429）。
Top1 画像（过滤版）：K_B=0.936、A_B=0.0、V_B=0.968——国外专利掌控 92% 以上、国内高价值专利为零，风险来自"国内空白"而非"国内被挤"。

## 复现

```powershell
cd 替代风险计算   # 项目根（所有脚本按 ROOT=项目根 解析路径）
# config.json 的 input_suffix："" = IPC 全量；"_filtered" = IPC 过滤
python 共用/scripts/run_all.py
python 共用/scripts/generate_report.py
```

前置（一次性）：`python 共用/scripts/prepare.py`（中间表，需本地原始数据，见仓库根 数据清单.md）；过滤版还需 `python 共用/scripts/filter_relevance.py`（LLM 相关性判定，需 DEEPSEEK_API_KEY）。

重跑产物默认落在根 `outputs/`，本目录 `outputs/` 为已归档副本（含 .bak 历史版本）。
