# 实验二：按技术路线配对（"宏观版"）

## 怎么做

从引文网络主路径（共 163 条）归纳成 3 条技术路线——P1 推送+测量、P2 数据平台、P3 投放优化；两两配成 6 个有序对"国外 Y 替代国内 X"（主题码 X→Y）。每对用与总 README 相同的公式（R = S × (M+V) ÷ 2）打分；K/A/V 按配对中 B 路线（Y）的全集计算（exposure 口径）。

## 结果

| 版本 | 总表文件 | 配对 | 风险最高（Top1） | 唯一达标候选（无"未达标"标记） |
|---|---|---|---|---|
| 配对全量 | `outputs/替代风险指标总表_paths.csv` | 6（全部参与排名） | P2→P1（国外P1 推送+测量 替代 国内P2 数据平台）R=0.435 | P1→P2（国外P2 数据平台 替代 国内P1 推送+测量）R=0.426 |
| 配对过滤后 | `outputs/替代风险指标总表_paths_filtered.csv` | 6 | P2→P1 R=0.442 | P1→P2 R=0.428 |

过滤版全表（R 降序）：P2→P1（0.442）、P1→P2（0.428）、P3→P1（0.428）、P2→P3（0.426）、P3→P2（0.420）、P1→P3（0.415）。
Top1 画像（过滤版）：K_B=0.945、A_B=0.016、V_B=0.964——风险差距主要来自"国外增长更快、主干道地位上升"，各对技术相似度相近。

## 复现

```powershell
cd 替代风险计算   # 项目根
# config.json 的 input_suffix："_paths" = 配对全量；"_paths_filtered" = 配对过滤
python 实验二_主路径配对/scripts/path_routes.py   # 前置：路线路由表 + 配对表
python 共用/scripts/run_all.py
python 共用/scripts/generate_report.py            # 路线版报告内嵌主路径全景概况
```

重跑产物默认落在根 `outputs/`，本目录 `outputs/` 为已归档副本（含全景概况与 .bak 历史版本）。
