# 实验二：按技术路线配对（"宏观版"）

> 从引文网络的技术发展主干道（主路径）归纳出 3 条大技术路线，两两配成"国外某路线替代国内某路线"共 6 对，计算替代风险。

## 完整过程（五步）

### 第 1 步：主路径识别（163 条技术发展主干道）

在引文网络（专利为节点、引用为边）上，用 SPC 算法（沿被引用最密集的路径加权寻路）找出 6 个时间窗口（2000 前、2000-2005、2000-2010、2000-2015、2000-2020、2000-2026）各自的"技术发展主干道"，共 **163 条主路径**（如 2000-2026 窗口 28 条）。每条路径是一串专利构成的链（如 `US20090024475A1 → US8392251B2 → …`），并带 SPC 权重（路径重要性）。

### 第 2 步：LLM 概括成 3 条技术路线（163 条 → 3 类）

163 条原生路径**不能直接当技术路线**：同一窗口内的路径高度重叠（如 2000-2026 窗口前 10 条路径的节点并集只有 27 个专利、互相共享 75%~100%——它们是同一条主干的十种走法），且窗口之间对不上号。因此把每个窗口的全部路径打包交给 LLM 按技术特征归纳分类（`路径概括与拓展` 模块），每个窗口归纳出 **3 个技术类**，LLM 同时为每类撰写"差异化特征"：

```
路径 1：侧重神经响应数据同步与位置感知的刺激材料呈现，并整合中枢/自主/效应器数据评估营销和娱乐有效性。
路径 2：侧重神经响应数据的储存库系统管理，提供高效的数据生成、管理、访问、查询、报告分析和可视化。
路径 3：侧重基于受试者神经响应测量评估和选择刺激材料引入的时空位置，优化刺激放置。
```

3 条路线 = **P1 推送+测量**（按位置推送刺激并测脑反应）、**P2 数据平台**（脑反应数据收集分析）、**P3 投放优化**（按脑反应决定刺激怎么放）。注意：**不是"从 28 条里挑 3 条"，而是"把 163 条重叠度极高的路径归纳成 3 类"**——每条路线覆盖全部窗口、全部路径。

### 第 3 步：路线归属与拓展（3 条路线 → 每条近千条专利）

路线的"骨架"（主路径节点）每窗口每条只有 9~15 个专利。以每条路线的专利为锚，在全库做语义相似度匹配（bge 嵌入预筛 + LLM 精判），把相似专利"并入"该路线（`路径概括与拓展` 模块的语义拓展）：

| 路线 | 专利数 | 中国专利 |
|---|---|---|
| P1 推送+测量 | 966 | 212 |
| P2 数据平台 | 866 | 232 |
| P3 投放优化 | 1031 | 261 |

### 第 4 步：跨路线配对（6 个有序对）

两两配对成"国外 Y 替代 国内 X"（X≠Y，共 3×2=6 对）。为什么必须**跨路线**配对：同一条路线内部国内外专利的原理天然相似，"原理差异"指标恒低、永远无法构成替代——替代发生在**不同技术路线之间**。

### 第 5 步：指标计算与排名（run_all.py）

每对用与实验一相同的公式 R = S × (M + V) ÷ 2 打分（三层定义见总 README）。**口径差异**：K/A/V（安全暴露度）按配对中 B 路线（Y）的**全集**计算（exposure 口径，文档要求），而非仅该对子集——即"国外这条路线的核心技术整体有多少在海外、国内整体自主能力如何"。

## 实验结论

1. **风险最高的是"国外 P1（推送+测量）替代国内 P2（数据平台）"（R=0.442）**——国外用"推送+测量"的技术路线挤压国内"数据平台"的位置；**唯一完全满足"替代候选"三条件的，是"国外 P2（数据平台）替代国内 P1（推送+测量）"（R=0.428）**——国外数据平台技术路线对国内推送测量环节构成教科书式替代（功能场景相似、原理不同、趋势上升）。
2. **排序由"替代成熟度"（M）决定**：6 对的"可替代性 S"几乎相同（0.596~0.603），差距全在"国外路线增长更快、主路径地位上升"——风险差异来自**成长性**，不是技术相似度。
3. **国内缺位警报贯穿**：三条路线的安全暴露度都接近上限（V≈0.96~0.98）——核心技术 95%~96% 在国外、中国高价值专利仅 1.1%~2.9%，无论哪对配对，性质都是"国外强势、国内空白"。

**结论解读提醒**：6 对的原理差异全部挤在 0.288~0.303 临界窄带，唯一达标对仅超阈值 0.003——"达标 1/6"应读作"唯一相对达标"而非稳健分类（实验三的主题对粒度解决了这个问题，见实验三 README）。

## 复现

```powershell
cd 替代风险计算   # 项目根
# config.json 的 input_suffix："_paths" = 配对全量；"_paths_filtered" = 配对过滤
python 实验二_主路径配对/scripts/path_routes.py   # 前置：路线路由表 + 配对表
python 共用/scripts/run_all.py
python 共用/scripts/generate_report.py            # 路线版报告内嵌主路径全景概况
```

前置（一次性）：`python 共用/scripts/prepare.py`；过滤版还需 `python 共用/scripts/filter_relevance.py`（需 DEEPSEEK_API_KEY）。
主路径识别与路线概括（第 1-2 步）由上游模块完成：`主路径识别/`、`路径概括与拓展/`（本实验的 `outputs/主路径全景概况.md` 展示全部 163 条主路径的技术主线）。
重跑产物默认落在根 `outputs/`，本目录 `outputs/` 为已归档副本（含全景概况与 .bak 历史版本）。
