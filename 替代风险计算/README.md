# 技术替代风险识别 — 实验说明

> 研究问题：**在国外技术路线快速发展的背景下，国内对应技术路线被替代的风险有多大？**

## 先看这里：本模块做了三份实验

### 实验一：按 IPC 主题排查（"细查版"）

**怎么做**：把研究数据集里的 2863 条脑机接口专利，按专利自带的 IPC 分类号分成 147 个"技术主题"（相当于 147 个文件夹，如 A61B5=身体诊断测量、A61N1=电疗器械）。对每个主题：把该主题的**中国专利**和**国外专利**各装一筐，比三件事——

1. 两筐专利**做的事像不像**（功能/场景相似度，用 AI 嵌入模型算）
2. 国外这筐**增长快不快、地位涨没涨**（专利数量增速 + 在技术主干道上的占比变化）
3. 被替代了**疼不疼**（该主题核心技术有多少在国外、中国有多少高价值专利）

三个分数合成一个风险分（0~1），147 个主题排座次。因为数据集混进了一些与脑机接口无关的专利（如位置广告），先让 AI 逐条判定（2969 条、100% 成功）剔除 370 条无关的，再算一遍。

**结果**：过滤后剩 133 个主题，38 个可参与排名，9 个达到"替代候选"标准。**风险最高的三个**：G06Q30 商业交易系统（神经营销，0.463）、A61N2 磁疗器械（0.430）、G06F17 数据处理（0.429）。它们的共同点是：国外专利占比 92% 以上、中国高价值专利几乎为零——**风险来自"国内空白"，不是"国内被挤"**。

### 实验二：按技术路线配对（"宏观版"）

**怎么做**：先从引文网络算出脑机接口技术 20 年来的"发展主干道"（主路径，共 163 条），再归纳成 **3 条大路线**——P1 推送+测量（按位置推送刺激并测脑反应）、P2 数据平台（收集分析脑反应数据）、P3 投放优化（按脑反应决定刺激怎么放）。然后两两配对："**国外某路线替代国内某路线**"共 6 对，每对用同样的三件事打分。

**结果**：6 对中**风险最高的是"国外 P1 替代国内 P2"（0.442）**——国外用"推送+测量"的技术路线挤压国内"数据平台"的位置；**唯一完全满足"替代候选"三条件的，是"国外 P2（数据平台）替代国内 P1（推送+测量）"（0.428）**。6 对的风险差距主要来自"国外增长更快、主干道地位上升"，技术相似度反而都差不多。

### 实验三：按知识要素凝练主题配对（"文档要求版"）

**怎么做**：严格按《替代风险计算研究方案.md》第三步执行——先用 LLM 逐条给 2493 条专利打技术主题标签（解析率 100%，其中 13 条因 LLM 回显公开号乱码未入主题，实际入主题 2480 条），归并聚类成 **45 个凝练主题**（如 C31=植入式神经接口系统、C8=神经刺激监测装置），再两两配成有序主题对（"国外主题 Y 替代国内主题 X"，45×44=1980 对）。与实验一/二的关键区别是文档口径的两道门槛：

1. **替代候选双前提**：两个主题须**解决同一类问题**（知识图谱"问题"实体的集合相似度≥0.5）且**原理明显不同**（H≥0.3）；
2. **硬阈值**：F≥0.6、C≥0.5、H≥0.3 **全过**才计算综合得分与风险；未过前提/未达阈值的对留表带标记、不参与排名。

**结果**：1980 对中 **30 对未过双前提、230 对未达硬阈值、1580 对达标并参与排名**。**风险最高的是"国外 C8 神经刺激监测装置 替代 国内 C31 植入式神经接口系统"（R=0.508）**，其后为"国外 C26 神经刺激电极装置 → 国内 C31"（0.491）、"国外 C8 → 国内 C35 神经刺激参数优化"（0.490）。风险最高的对里，被替代侧（X）的国内专利多为 0（如 C31 国内无专利）或很少（C35 国内仅 12 条）、替代侧（Y）核心技术 95% 以上在国外——与前两份实验完全一致：**国外主导、国内缺位**。

### 三份实验的关系

实验一像**拿着放大镜逐个文件夹排查**（谁风险高），实验二像**站在高处看三条大道之间谁在替代谁**（宏观结构），实验三是**按研究方案原文口径的严格版**（先验证"解决同类问题 + 原理不同"，再算风险）。三份实验的结论一致：风险靠前者都是"国外主导 + 国内缺位"，而且**剔除无关专利前后结论不变**——结论是稳的。

## 风险公式：一个问题拆成三层

替代风险 **R = S × (M + V) ÷ 2**，三层各回答一个子问题：

| 层 | 符号 | 子问题 | 怎么算 | 数据来源 |
|---|---|---|---|---|
| 可替代性 | **S** | 国外技术**能不能**替代国内技术？ | 功能相似度 F + 场景相似度 C + 原理差异度 H 的加权和（F/C 用 bge 嵌入的语义相似度，H=1−原理相似度） | 知识图谱实体集合 |
| 替代成熟度 | **M** | 替代**正在发生**吗？ | M=(G+T)/2：G=国外路线专利增速是否快于国内（6 窗口对数增长斜率）；T=国外路线在主路径中的占比是否上升 | 引文网络 + 专利年份 |
| 安全暴露度 | **V** | 被替代了**疼不疼**？ | V=(K+1−A)/2：K=核心技术被国外掌控的比例（按被引加权）；A=中国高价值专利（被引前 10%）占比 | 引文网络被引次数 |

**直觉**：三条都高才是真风险——只是"长得像"（S 高）但趋势没来（M 低），或国外虽快（M 高）但技术路子不同（S 低），都不能判为替代；国内自己有家底（A 高），被替代也不致命（V 低）。

## 为什么做"过滤前后"、"跨路线配对"与"文档口径门槛"

- **过滤前后**：研究数据集由语义匹配扩展而来，混入了无关专利（如位置广告），需经 AI 逐条判定剔除后重算，确保结论不被污染。
- **跨路线配对**：同一条路线内部国内外专利的原理天然相似，"原理差异"指标恒低、永远无法构成替代——替代发生在**不同技术路线之间**。
- **文档口径门槛**（实验三）：研究方案 3.3 要求替代候选先满足"解决同一类问题 + 原理明显不同"双前提、再满足 F/C/H 硬阈值才算数——实验三把这条原文口径落地为可复现的流水线；主题对粒度下 H 分布拉开（0.279~0.493），"达标"判定不再像实验二那样挤在临界窄带（0.288~0.303）。

## 关键口径决策

| 口径 | 取值 | 理由 |
|---|---|---|
| 国内/国外 | 公开国家（CN=国内） | 数据 100% 覆盖，可复现 |
| 相似度 | bge-small-zh-v1.5 嵌入的对称最佳匹配 | 字符串比对对同义异形零容错（92% 主题零交集），嵌入后全部可计算 |
| 达标阈值 | F≥0.6、C≥0.5、H≥0.3（文档值） | 实验一/二为软阈值参考标记（不影响排名）；实验三为硬阈值（全过才计算，文档口径） |
| 替代候选双前提 | 问题实体相似度≥0.5 且 H≥0.3（仅实验三） | 文档 3.3 原文："解决同一类技术问题"+"原理明显不同" |
| 归一化 | sigmoid(2x) | 无差异=0.5，可比 |
| 专利权重 q | 被引次数+1 | 被引越多越核心 |
| 高价值专利 | 被引前 10%（≥44 次） | 文档口径 |
| 主路径窗口 | pre2000~2000-2026 共 6 个 | 覆盖技术演化全程 |

## 复现

```powershell
python -m pytest tests -v           # 69 个测试
python scripts/prepare.py           # 中间表（需本地原始数据，见仓库根 数据清单.md）
python scripts/embed_similarity.py  # 实体嵌入相似度
python scripts/theme_discovery.py   # 实验三：LLM 主题标签+归并聚类（需 DEEPSEEK_API_KEY）
python scripts/theme_pairs.py       # 实验三：主题版专利表（KG 问题实体 + 主路径拷贝）
python scripts/run_all.py           # 指标总表（离线环境自动使用本地 HF 缓存）
python scripts/generate_report.py   # 报告
```

版本切换：`config.json` 的 `input_suffix` = `""`（IPC 全量）/ `"_filtered"`（IPC 过滤）/ `"_paths"`（配对全量）/ `"_paths_filtered"`（配对过滤）/ `"_theme"`（主题对，文档口径）。
LLM 相关性判定：`python scripts/filter_relevance.py`（需 DEEPSEEK_API_KEY 环境变量，不落盘）。
