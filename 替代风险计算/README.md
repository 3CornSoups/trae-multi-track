# 技术替代风险识别 — 实验说明

> 研究问题：**在国外技术路线快速发展的背景下，国内对应技术路线被替代的风险有多大？**
> 本实验以脑机接口（BCI）专利为对象，把这个问题拆成三个子问题量化回答。

## 一、总体思路

```
专利引文网络 ──→ 主路径识别（技术发展主干道，6 个时间窗口）
                        │
                        ↓
        研究数据集 = 主路径专利 + 语义相似专利（2863 条）
                        │
                        ↓
        LLM 实体抽取 → 知识图谱（每专利的功能/场景/原理实体）
                        │
                        ↓
        BCI 相关性过滤（LLM 逐条判定，剔除混入的无关专利）
                        │
                        ↓
        替代风险计算（本模块）
```

## 二、风险识别逻辑：一个问题拆成三层

替代风险 **R = S × (M + V) ÷ 2**，三层各回答一个子问题：

| 层 | 符号 | 子问题 | 怎么算 | 数据来源 |
|---|---|---|---|---|
| 可替代性 | **S** | 国外技术**能不能**替代国内技术？ | 功能相似度 F + 场景相似度 C + 原理差异度 H 的加权和（F/C 用 bge 嵌入的语义相似度，H=1−原理相似度） | 知识图谱实体集合 |
| 替代成熟度 | **M** | 替代**正在发生**吗？ | M=(G+T)/2：G=国外路线专利增速是否快于国内（6 窗口对数增长斜率）；T=国外路线在主路径中的占比是否上升 | 引文网络 + 专利年份 |
| 安全暴露度 | **V** | 被替代了**疼不疼**？ | V=(K+1−A)/2：K=核心技术被国外掌控的比例（按被引加权）；A=中国高价值专利（被引前 10%）占比 | 引文网络被引次数 |

**直觉**：三条都高才是真风险——只是"长得像"（S 高）但趋势没来（M 低），或国外虽快（M 高）但技术路子不同（S 低），都不能判为替代；国内自己有家底（A 高），被替代也不致命（V 低）。

## 三、实验设计：四个版本互为验证

| 版本 | 技术路线划分 | 数据 | 用途 |
|---|---|---|---|
| IPC 主题版 | 147 个 IPC 大组（如 A61B5 身体诊断测量） | 全量 | 细粒度排查 |
| 路径配对版 | 3 条主路径概括路线（P1 推送+测量 / P2 数据平台 / P3 投放优化），**跨路线配对** 6 对（国外Y 替代 国内X） | 全量 | 宏观轨道级结论 |
| 以上两版 × 过滤前后 | 同左 | 剔除无关专利后（2493 条） | 检验结论稳健性 |

为什么有"过滤前后"：研究数据集由语义匹配扩展而来，混入了与 BCI 无关的专利（如位置广告），需经 LLM 逐条判定（2969 条，100% 成功）剔除 370 条后再算，确保结论不被污染。

为什么配对版用"跨路线"：同一条路线内部国内外专利的原理天然相似，"原理差异"指标恒低、永远无法构成替代——替代发生在**不同技术路线之间**（如"数据平台"技术替代"推送测量"环节）。

## 四、关键口径决策

| 口径 | 取值 | 理由 |
|---|---|---|
| 国内/国外 | 公开国家（CN=国内） | 数据 100% 覆盖，可复现 |
| 相似度 | bge-small-zh-v1.5 嵌入的对称最佳匹配 | 字符串比对（Jaccard）对同义异形零容错，92% 主题零交集；嵌入后 48/48 可计算主题全部有正相似度 |
| 达标阈值 | F≥0.6、C≥0.5、H≥0.3（文档值） | 作"替代候选"参考标记；软阈值口径下不影响排名 |
| 归一化 | sigmoid(2x) | 无差异=0.5，可比 |
| 专利权重 q | 被引次数+1 | 被引越多越核心 |
| 高价值专利 | 被引前 10%（≥44 次） | 文档口径 |
| 主路径窗口 | pre2000~2000-2026 共 6 个 | 覆盖技术演化全程 |

## 五、结果速览（详见 outputs/风险分析报告.md）

- **IPC 版（过滤后）**：133 主题 / 38 参与排名 / 9 达标；Top-3 = G06Q30 神经营销（0.463）、A61N2 磁疗（0.430）、G06F17 数据处理（0.429）
- **配对版（过滤后）**：6 对中"国外 P1 替代国内 P2"风险最高（0.442）；唯一达标候选 = "国外 P2 替代国内 P1"（0.428）
- **性质**：风险靠前者均为"国外主导 + 国内缺位"——核心技术 95%+ 在国外、中国高价值专利仅 1~3%

## 六、复现

```powershell
python -m pytest tests -v           # 59 个测试
python scripts/prepare.py           # 中间表（需本地原始数据，见仓库根 数据清单.md）
python scripts/embed_similarity.py  # 实体嵌入相似度
python scripts/run_all.py           # 指标总表
python scripts/generate_report.py   # 报告
```

版本切换：`config.json` 的 `input_suffix` = `""`（IPC 全量）/ `"_filtered"`（IPC 过滤）/ `"_paths"`（配对全量）/ `"_paths_filtered"`（配对过滤）。
LLM 相关性判定：`python scripts/filter_relevance.py`（需 DEEPSEEK_API_KEY 环境变量）。
