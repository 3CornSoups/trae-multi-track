## 二、主路径国别分布：为什么只有中美？

### 数据事实

**主路径上（共84项专利）**:
| 国家 | 主路径专利数 | 主路径占比 |
|------|:----------:|:----------:|
| 🇺🇸 美国 | 61 | 72.6% |
| 🇨🇳 中国 | 23 | 27.4% |
| 🇰🇷 韩国 | 0 | 0% |
| 🇪🇺 欧洲(EP) | 0 | 0% |
| 🇯🇵 日本 | 0 | 0% |

**全数据集中（72,583项专利）**:
| 国家 | 专利数 | 占比 |
|------|:------:|:----:|
| 美国 | 29,208 | 40.2% |
| 中国 | 17,417 | 24.0% |
| 韩国 | 6,519 | 9.0% |
| 欧洲(EP) | 4,149 | 5.7% |
| 日本 | 2,820 | 3.9% |

**结论**: 日本（2,820项）、韩国（6,519项）、欧洲（4,149项）的BCI专利在全数据集中确实存在且体量不小，但**在全球技术演化主路径上占比均为零**。

### 为什么这是正常且有价值的发现？

**1. 算法机制使然——SPC天然筛选"主干道"**

SPC（Search Path Count）衡量的是"一条边在所有源→汇路径中被经过的频率"。美国29,208项专利占据了全球引文网络最大弱连通分量（175K节点）的核心位置。日、韩、欧的专利虽然数量不少，但它们形成的引文子网络处于更边缘的位置——技术被引用和扩散的广度不够，无法进入全球技术演化的"主干道"。

**2. 这恰恰印证了论文的核心论点**

论文要论证的是"技术锁定（lock-in）"——核心技术轨道被少数国家垄断。现在的结果比预期更极端：**不是"中美竞争"，而是"美国主导+中国在应用层追赶，日韩欧整体缺位"**。这是一个更强有力的发现。

**SPC的"马太效应"**: SPC算法天然放大主导者的优势——美国不仅在数量上占优（40%），更重要的是它的专利处于引文网络的结构中心。这就像道路交通网：主干道流量越大，导航系统越推荐走主干道，主干道变得更重要——形成正反馈循环。

**3. 方法论局限的坦诚说明**

SPC + Key-Route 偏向最大的连通分量，可能导致：

- 日本/韩国/欧洲的专利可能形成了**独立的、小规模的技术子轨道**（比如日本可能在某种特定的非侵入式BCI传感器上有自己的技术路线），但因为整体SPC值不够高而被主路径算法"忽略"
- 这不代表日韩欧在BCI领域"没有专利"，而是说它们没有出现在**全球技术演化的最高流量主干上**
- 如果审稿人质疑，可以回应：SPC+Key-Route是文献中的标准方法；日韩欧的专利在全数据集中确实存在且数量不少，只是引用影响力不足以进入主干——这正是"技术边缘化"的量化证据

### 论文写作建议

在主路径分析部分可加入一段"意外发现"：

## 三、实验核心发现回顾（来自WORK_REPORT.md）

### 提取的5条主路径

| 路径 | 节点 | 年份 | CN专利 | 技术主题 |
|------|------|------|--------|---------|
| #1 | 23 | 1977→2025 | **13** (57%) | BCI(SSVEP/P300)→康复&交互 |
| #2 | 22 | 1966→2024 | **10** (45%) | BCI→多模态交互&控制 |
| #3 | 22 | 1975→2023 | **0** (0%) | EMG→手势识别 |
| #4 | 17 | 1993→2018 | **0** (0%) | 医疗监控→可穿戴传感器 |
| #5 | 14 | 1977→2025 | **0** (0%) | 神经接口→连续运动控制 |

### 关键发现

1. **中国BCI专利的"应用层依赖"**: 中国专利集中在路径#1和#2上，且全部处于技术链下游应用层（康复训练、智能家电控制、AR交互）。上游的脑电信号处理、神经接口系统、生物传感器专利仍属外国。

2. **三条技术轨道中国完全缺位**:
   | 缺失轨道 | 外国主导 | 风险 |
   |---------|---------|------|
   | EMG神经肌肉接口 | Meta(CTRL-Labs) | 下一代人机交互核心技术 |
   | 可穿戴医疗传感器 | Masimo, Medtronic | 医疗级BCI硬件入口 |
   | 神经接口运动控制 | Neuralink, Kernel | 侵入式/高精度脑机接口 |

3. **时间维度**: 2012年前主路径无中国专利；2012-2018中国开始在SSVEP/P300方向出现；2018-2025密集出现但仅限应用层。

4. **技术锁定**: 外国专利在核心BCI信号处理、神经接口系统等上游环节形成强锁定，中国主要集中在应用层，缺乏对底层技术的占位。
