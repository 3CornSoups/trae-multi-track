## 7. 风险与保障

- **可恢复性**：所有删除均在压缩 + 校验通过后进行；校验 = `unzip -t`（可读性）+ 文件数/大小对比
- **磁盘空间**：压缩前检查可用空间（新增 zip 预计 ~700-900MB，paper-project 压缩最耗时，需在后台运行）
- **脚本正确性**：改名后逐脚本检查引用路径存在性，用 Python 快速导入/试跑轻量步骤验证
- **不触碰**：`.claude/`、`.superpowers/`、`.playwright-mcp/`、父目录 `0817多轨道`（空目录）
- **注意**：项目非 git 仓库，删除不可版本恢复，故全部依赖压缩归档保障
