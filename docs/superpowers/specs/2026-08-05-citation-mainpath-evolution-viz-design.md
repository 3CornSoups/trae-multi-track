# 引文网络与主路径演化可视化 — 设计规格

> 日期：2026-08-05  
> 状态：待用户审阅  
> 交付目录：`引文网络和主路径演化/`

## 1. 目标

用**单一前端页面**呈现 BCI 专利引文网络在多个累积时间窗口下的**主路径演化**。核心视觉为同心圆环：内环为最早窗口，外环为后续窗口；路径连线是否跨环直观反映轨道延续与分化。

本页**不以**完整引文网络或分窗口力导向图为主视图。

## 2. 已确认决策

| 项 | 决策 |
|----|------|
| 页面结构 | 以演化为主（同心环单视图） |
| 节点内容 | 主路径节点 + 高被引背景点 |
| 落环规则 | 按「首次进入主路径 / 首次进入背景 Top」的窗口落环，全局只画一次 |
| 路径数量 | 每窗口 SPC Top-5 |
| 交互 | 轻交互（悬停、显隐、缩放平移） |
| 技术栈 | 静态 HTML + D3.js；Python 预处理 JSON |

## 3. 数据范围

### 3.1 时间窗口（5 环，从 2000 年起）

| 环序（内→外） | 窗口 ID | 标签 |
|--------------|---------|------|
| 1 | `2000_2005` | 2000–2005 |
| 2 | `2000_2010` | 2000–2010 |
| 3 | `2000_2015` | 2000–2015 |
| 4 | `2000_2020` | 2000–2020 |
| 5 | `2000_2026` | 2000–2026 |

不包含 `pre2000`。

### 3.2 数据源

| 用途 | 路径 |
|------|------|
| 主路径序列 | `主路径识别/outputs/window_*_sequences.csv` |
| 主路径汇总 | `主路径识别/outputs/window_*_summary.json`、`windows_comparison.json` |
| 窗口网络节点（入度） | `专利数据合并与引文网络构建/citation_network_windows/nodes_window_*.csv` |
| 专利元数据（可选补全） | `专利数据合并与引文网络构建/merged_patent_info.csv` 或 sequences 内已有字段 |

## 4. 数据裁剪规则

### 4.1 主路径节点

1. 对每个窗口，按 SPC 取 Top-5 路径（与 `summary` / `paths_all` 排序一致）。
2. 收集这些路径上的全部 `patent_no`。
3. **落环**：专利第一次出现在任一窗口 Top-5 主路径中的窗口；之后窗口再出现同一专利时不再新建节点，仅参与连线。

### 4.2 高被引背景点

1. 对每个窗口，按 `in_degree_window` 取 Top-20。
2. 剔除已是主路径节点的专利。
3. **落环**：专利第一次进入某窗口背景 Top-20 的窗口；全局只画一次。
4. 样式弱于主路径节点；可悬停，不参与路径图例开关逻辑。

### 4.3 路径边

- 仅输出各窗口 Top-5 主路径的有序边（`source → target` 沿路径顺序）。
- 每条路径带：`window`、`path_id`、`total_spc`、节点序列。
- **不渲染**全量引文边。

### 4.4 规模预期

- 主路径节点：约数十～百余（去重后）。
- 背景点：≤ 5 × 20 = 100（去重后更少）。
- 路径：5 × 5 = 25 条。

## 5. 可视化布局

### 5.1 几何

- 画布中心为圆心；5 个同心环，半径等差递增。
- 环带颜色区分窗口（固定色板，浅色学术风，避免默认紫/奶油模板）。
- 节点落在对应环的圆周附近（允许径向小抖动避碰）。

### 5.2 角度排布

1. 同环内主路径节点：按路径聚类，使同路径节点角度相邻。
2. 轻量碰撞/斥力，减少重叠。
3. 背景点填入空隙，弱化显示。

### 5.3 路径绘制

- 二次贝塞尔曲线，控制点略离圆心，突出跨环。
- 路径颜色按所属窗口；同窗口多条路径用透明度或线型区分。
- 跨环线段语义：该路径使用了更早窗口已落下的节点 → 轨道延续。

## 6. 页面结构与交互

### 6.1 布局

```
┌─────────────────────────────────────────────────────────┐
│  标题：引文网络与主路径演化 + 一句说明                      │
├──────────┬──────────────────────────────┬───────────────┤
│  图例    │                              │  详情卡       │
│  · 环色  │     同心圆环主视图            │  公开号/标题  │
│  · 路径  │     （可缩放平移）            │  申请年/窗口  │
│  · 开关  │                              │  所属路径     │
└──────────┴──────────────────────────────┴───────────────┘
```

### 6.2 交互清单

| 操作 | 行为 |
|------|------|
| 滚轮 | 缩放 |
| 拖拽背景 | 平移 |
| 悬停节点 | 右侧详情；高亮经过该节点的路径 |
| 点击路径图例 | 显隐该路径 |
| 点击环图例 | 显隐该环**背景点**（主路径节点始终显示） |
| 点击空白 | 取消高亮 |

### 6.3 动效

- 入场：环淡入 → 节点出现 → 路径描边（共 2–3 处，短促）。
- 不做时间轴自动播放。

### 7.2 JSON 契约（要点）

```json
{
  "meta": {
    "title": "...",
    "windows": [
      { "id": "2000_2005", "label": "2000–2005", "ring": 0, "color": "..." }
    ],
    "generated_at": "..."
  },
  "nodes": [
    {
      "id": "US...",
      "type": "mainpath" | "background",
      "ring": 0,
      "app_year": 2003,
      "country": "US",
      "title": "...",
      "title_cn": "...",
      "in_degree": 12,
      "first_window": "2000_2005"
    }
  ],
  "paths": [
    {
      "window": "2000_2005",
      "path_id": 1,
      "total_spc": 8128.7,
      "nodes": ["US...", "US..."]
    }
  ]
}
```

节点坐标由前端布局计算，JSON 不预存 `x/y`（除非预处理阶段做离线布局；默认前端布局）。

### 7.3 依赖

- 前端：D3 v7（CDN）。
- 预处理：Python 3 + pandas（与现有脚本环境一致）。
- 打开方式：本地静态服务器或直接打开 `index.html`（若 CDN 可用）。

### 7.4 函数注释

所有自写 JS/Python 函数须有**中文**函数级注释。

## 8. 非目标（本版不做）

- 全量引文网络力导向图 / 分窗口独立网络页
- 每窗口超过 Top-5 的路径滑块
- 时间轴自动播放演化动画
- 后端服务或构建工具链（Vite/React 等）
- pre-2000 窗口

## 9. 验收标准

1. 双击或本地打开页面后，可见 5 环 + Top-5×5 路径 + 背景点。
2. 同一专利不重复落在多环。
3. 悬停可看专利信息；路径与背景点可按图例显隐。
4. 缩放平移流畅（节点量级百级）。
5. 运行 `prepare_viz_data.py` 可从现有 outputs 重生 `viz_data.json`。

## 10. 实现顺序（概要）

1. 编写 `prepare_viz_data.py`，产出 `viz_data.json` 并人工抽查落环逻辑。
2. 搭建 `index.html` 壳与样式。
3. 实现同心环 + 节点布局 + 路径绘制。
4. 接轻交互与详情卡。
5. 写 README，本地验收。
