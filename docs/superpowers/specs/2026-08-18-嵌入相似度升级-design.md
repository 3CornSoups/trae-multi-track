# 替代风险计算 — 实体嵌入语义相似度升级 设计文档

> 日期：2026-08-18
> 前置：2026-08-17 替代风险计算流水线（`替代风险计算/`，28 测试全绿）已完成
> 动机：Jaccard 口径下 147 主题 F/C 全部未达标（F>0 仅 8.2%），诊断结论为"LLM 实体碎片化 + Jaccard 只认字符串相等 + 阈值按语义尺度设计"的尺度错配，非计算错误。

## 1. 目标

将 F/C/H 的实体集合相似度从 Jaccard 升级为 **bge-small-zh-v1.5 嵌入的对称最佳匹配均值**；Jaccard 值保留为对照列（F_J/C_J/H_J）；S_AB、"未达标"标记、风险排名改用嵌入口径。文档阈值（F≥0.6/C≥0.5/H≥0.3）保留为"达标"参考标记（软阈值口径不变）。

## 2. 口径决策（2026-08-18 用户确认）

1. **集合相似度公式**（用户选定）：对称最佳匹配均值
   sim(A,B) = ½·[mean_{a∈A} max_{b∈B} cos(a,b) + mean_{b∈B} max_{a∈A} cos(a,b)]
   对集合规模悬殊（如 914 vs 2208）稳健；直觉=平均语义重合度。
2. **阈值**（用户选定）：保留文档阈值 F≥0.6/C≥0.5/H≥0.3 作为达标参考标记。
3. **对照列**（用户批准）：总表 25→28 列，S_AB 后插入 F_J/C_J/H_J。
4. **模型**：`BAAI/bge-small-zh-v1.5`（本地 HF 缓存已有，无联网；torch CPU 2.13；sentence_transformers 5.6.1），沿用 `语义相似度匹配/scripts/embed.py` 的加载模式（normalize_embeddings=True + npy 缓存）。

## 3. 公式落地

- entity_sim_by_topic.csv 存三类集合相似度：F_sim（采用）、C_sim（应用于）、P_sim（基于）
- run_all 组装：F = F_sim；C = C_sim；H = 1 − P_sim；S = w1·F + w2·C + w3·H
- 空集合（任一侧无该关系实体）：该维度相似度=0
- Jaccard 三值仍由 per_topic_indicators 内部计算并输出为 F_J/C_J/H_J
