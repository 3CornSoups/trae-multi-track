## 1. 目标

依据文档三步研究流程的第三步，基于已建成的知识图谱、引文网络与主路径识别结果，对 147 个 IPC 大组级技术主题逐主题计算：

- 技术可替代性 **S_AB**（国内路线 A vs 国外路线 B，同一技术主题的两个子集）
- 相对增长优势 **G_AB**、主路径地位转移 **T_AB**、替代成熟度 **M_AB**
- 国内安全暴露度 **V_B**（国外核心专利控制度 K_B + 国内自主能力 A_B）
- 最终替代风险 **R_AB = S_AB × (M_AB + V_B)/2**

产出：指标总表 CSV + Markdown 报告（论文方法章节素材）。

## 2. 数据源

| 数据 | 文件 | 用途 |
|---|---|---|
| 知识图谱 | `实体抽取，知识图谱构建/bci知识图谱数据包.zip`（graph_nodes.csv / graph_edges.csv / ipc_subtopic_map.csv） | 专利实体集合（功能/场景/原理）、技术主题归属、公开国家、公开年 |
| 主路径 | `主路径识别/outputs/window_*_edges.csv`（6 窗口：pre2000、2000_2005、2000_2010、2000_2015、2000_2020、2000_2026） | 各窗口主路径节点集 |
| 引文网络 | `专利数据合并与引文网络构建/citation_network_full/nodes.csv`（in_degree） | 专利权重 q_i 与高价值专利判定 |

## 3. 口径决策（2026-08-17 用户确认）

1. **国内/国外划分**：公开国家。CN=国内，其余（US/WO/EP/KR/JP 等）=国外。
2. **技术路线**：KG 现有 147 个 IPC 大组级技术主题（主IPC 分类号 → `属于` 边；`ipc_subtopic_map.csv` 提供中文名）。
3. **实体集合映射**：功能→`采用`（技术方法）、场景→`应用于`（应用场景）、原理→`基于`（技术原理）。实体名用消歧后的规范名（graph_nodes.csv 的 name 字段）。
4. **相似度方法**：Jaccard 为主体（本地、可复现）；LLM 复核为可选后续步骤（不在本次范围）。
5. **归一化**：sigmoid，Norm(x) = 1/(1+e^(−2x))。无差异=0.5，B 越占优越趋近 1。
6. **专利权重 q_i**：in_degree + 1（被引次数 +1；引文网络中不存在的专利按 in_degree=0）。
7. **高价值专利**：全数据集被引次数 top 10%（约 ≥44 次）。
8. **权重与阈值**：文档默认 w1=w2=w3=1/3；F≥0.6 且 C≥0.5 且 H≥0.3 才计算 S。
9. **K_B 口径**：按**主题全集**（国内+国外）计算加权国外占比——若严格按文档"i∈B"只取国外子集则 K_B 恒为 1，无信息量，故采用全集解读。
10. **T_AB 窗口**：6 窗口，初期=pre2000、末期=2000-2026（用户确认纳入 pre2000 缓解稀疏）。

## 4. 公式定义

### 4.1 实体集合相似度（Jaccard）

设主题 X 的国内专利集 A、国外专利集 B，三类实体集合：

- F_AB = Jaccard(采用实体集_A, 采用实体集_B)
- C_AB = Jaccard(应用于实体集_A, 应用于实体集_B)
- H_AB = 1 − Jaccard(基于实体集_A, 基于实体集_B)

Jaccard(P,Q) = |P∩Q| / |P∪Q|；双方均为空集时定义为 0。

### 4.2 可替代性

前置条件（文档"替代候选"两条件）：①"解决同一类问题"——配对为同一技术主题的国内外子集，天然满足；②"技术原理存在明显差异"——由 H≥0.3 阈值落实。

S_AB = w1·F_AB + w2·C_AB + w3·H_AB，仅当 F≥0.6 且 C≥0.5 且 H≥0.3 时计算，否则 S=NaN 并标记 `未达阈值`。

### 4.3 增长与转移

- N_A,t = 主题 X 国内专利中公开年 ≤ t 末的累计数（t ∈ 6 窗口）；g_A = slope[ln(1+N_A,t)]，x=0..5 等间隔线性回归斜率（numpy polyfit，1 阶）。
- G_AB = sigmoid(2·(g_B − g_A))
- p_A,t = 窗口 t 主路径去重节点中"主题 X 且国内"专利数 / 窗口 t 主路径去重节点总数（无 IPC 归属的外部节点计入分母）
- Δp_A = p_A,末期 − p_A,初期；T_AB = sigmoid(2·(Δp_B − Δp_A))
- M_AB = (G_AB + T_AB) / 2

### 4.4 安全暴露度

- K_B = Σ_{i∈X} q_i·Foreign_i / Σ_{i∈X} q_i，q_i = in_degree+1，Foreign_i = 1（公开国家≠CN）/ 0（CN）
- A_B = 主题 X 内高价值专利（全数据集被引 top10%）中 CN 专利数 / 主题 X 内高价值专利总数；主题内无高价值专利 → A=NaN 并标记
- V_B = (K_B + 1 − A_B) / 2；A=NaN 时 V=NaN 并标记

### 4.5 最终风险

R_AB = S_AB × (M_AB + V_B)/2。S、V 任一为 NaN 时 R=NaN 并标记。

## 5. 边界规则

| 情形 | 处理 |
|---|---|
| 主题内国内或国外专利 < 3 个 | 标记 `样本不足`，保留 CSV 行但不进风险排名 |
| F/C/H 未达阈值 | S=NaN，标记 `未达阈值` |
| 主题无高价值专利 | A=NaN，V/R=NaN，标记 `无高价值专利` |
| 主路径节点无 IPC/无主题归属 | 计入主路径分母，不计入任何主题分子 |
| 40 个无有效主IPC 的 KG 专利 | 无 `属于` 边，不进入任何主题 |
| 13 个无摘要专利 | 不在 KG 中，仅可能出现在主路径节点（按上条处理） |
| 引文网络中查不到的专利 | in_degree 按 0 计 |
| 专利在 KG 中缺失公开年 | 不计入 N_A,t 累计（实现时统计并报告缺失数） |

## 6. 脚本结构

```
替代风险计算/
├── config.json              # 参数：weights、thresholds、sigmoid_k、windows、min_patents、
│                            #       高价值分位数、实体关系映射
├── scripts/
│   ├── prepare.py           # → outputs/intermediate/patent_route.csv、mainpath_nodes_by_window.csv
│   ├── indicators.py        # 纯函数：jaccard、sigmoid_norm、growth_slope、per_topic_indicators
```

## 7. 输出

1. `outputs/替代风险指标总表.csv`：每主题一行。列：主题码、主题中文名、n_国内、n_国外、F_AB、C_AB、H_AB、S_AB、g_A、g_B、G_AB、p_A初期、p_A末期、p_B初期、p_B末期、T_AB、M_AB、K_B、A_B、V_B、R_AB、标记。
2. `outputs/替代风险报告.md`：方法与公式、参数清单、Top-20 风险主题表+解读、S×M 态势分级（S 高 M 低 / S 高 M 高 / S 低 M 高）、数据质量与局限（主路径节点稀疏 21~43/窗口、K_B 全集口径说明、公开国家口径局限）。
3. `outputs/intermediate/`：中间表（可复核）。

## 8. 测试

pytest 覆盖 `indicators.py` 纯函数：

- jaccard：空集×空集=0、无交集=0、全同=1、部分交集
- sigmoid_norm：Norm(0)=0.5、单调递增、对称性 Norm(−x)=1−Norm(x)
- growth_slope：已知线性序列斜率正确（指数增长 → g≈增长率的对数形式验证）
- K_B/A_B：小型固定样例（含 Foreign 混合、高价值判定）
- 阈值过滤逻辑：未达阈值 → S=NaN 且标记
- 样本不足标记

## 9. 风险与局限（写进报告）

- 主路径各窗口节点仅 21~43 个（pre2000 182），p_A,t 稀疏，T_AB 噪声较大——报告如实说明。
- 公开国家 ≠ 最终控制权；申请人国籍覆盖仅 57%，故未采用。
- Jaccard 对未消歧的同义实体略低估相似度；图谱已做 LLM 语义消歧（n<5 小组未逐组审核，存在残余误并）。
- sigmoid k=2 为默认参数，可调（config.json）。
