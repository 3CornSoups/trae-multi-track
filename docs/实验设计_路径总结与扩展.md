## 任务一：LLM 生成五条主路径综合总结

### 输入

- 每条路径上所有专利的：标题（中文）、摘要（中文）、年份、国别
- 来源：`01-citation-network/outputs/patent_info.csv` + `02-main-path/outputs/main_path_sequences.csv`

### 方法

- 将每条路径的专利摘要按年份排序后拼接
- 使用 DeepSeek API（`deepseek-v4-flash`）生成结构化分析
- API 配置：`sk-****(已脱敏)` @ `https://api.deepseek.com`

### 输出维度（每条路径）

| 维度 | 说明 |
|------|------|
| 技术主题 | 该路径解决什么核心问题 |
| 技术原理 | 采用什么方法/原理（如SSVEP、P300、EMG、运动想象等） |
| 关键部件/材料 | 涉及哪些硬件/传感器/材料/算法组件 |
| 应用场景 | 医疗康复、人机交互、智能控制、可穿戴等 |
| 时间演化特征 | 1990s→2000s→2010s→2020s 各阶段技术特征变化 |
| 中国角色定位 | 该路径上中国专利的技术层级（基础层/中间层/应用层） |
| 路径特征标签 | 3-5个关键词（如"非侵入式""多模态融合""消费级""医疗级"等） |

### 输出文件

- `03-path-summary/outputs/path_{1-5}_llm_summary.md` — 每条路径的详细分析
- `03-path-summary/outputs/path_summary_overview.json` — 结构化摘要（含所有维度的键值对）

## 任务二：基于 TF-IDF + 余弦相似度的路径扩展

### 核心设计选择

| 维度 | 选择 | 理由 |
|------|------|------|
| 相似度方法 | **TF-IDF + 余弦相似度** | 所有专利均有中文翻译；**使用字符级 n-gram (2-4字) 替代 jieba 分词**，避免 7 万条摘要的分词瓶颈 |
| 分词策略 | **字符级 n-gram (2-4字)** | 中文专利术语的字符组合本身具有强区分度；sklearn `char_wb` analyzer，无需外部分词器 |
| 路径语义代表 | **策略B — 最大相似度法** | 保留路径内各专利多样性，候选专利只需与路径内某一专利高度相似即可归入 |
| 筛选策略 | **Top-50 + cosine ≥ 0.6** | 确保质量和数量可控；先计算所有相似度，取 top-50 后过滤低于 0.6 的 |
| 多路径归属 | **允许** | 专利可跨多个技术方向，最终标注"独占专利"与"跨路径专利" |

### 详细步骤

```
Step 1: 数据准备
  - 加载 patent_info.csv（72,583 条，97% 有摘要）
  - 加载 main_path_sequences.csv（5 条路径，84 个核心专利）
  - 摘要预处理：中文分词（jieba）、去停用词

Step 2: TF-IDF 向量化
  - 对全部 7 万条摘要构建 TF-IDF 矩阵
  - 参数: max_features=10000, ngram_range=(1,2), min_df=2
  - 使用 sklearn TfidfVectorizer

Step 3: 计算相似度
  - 对每条主路径，取路径内所有专利的 TF-IDF 向量
  - 对每个候选专利，计算其与路径内每个专利的余弦相似度，取最大值
  - 记录: patent_id, path_id, max_similarity, best_match_patent

Step 4: 筛选
  - 每条路径按 max_similarity 降序排列
  - 取 Top-50（含 cosine ≥ 0.6 约束）
  - 标记路径归属类型: "core"（原主路径专利）| "exclusive"（仅属于该路径）| "shared"（属于多条路径）

Step 5: 输出
  - path_{id}_expanded.csv — 扩展后的路径专利列表（含相似度得分和归属类型）
  - path_expansion_summary.json — 扩展统计（各路径新增数、独占比、跨路径数）
  - similarity_matrix_heatmap.png — 路径间语义相似度热力图（5×5）
```

### 输出文件

- `03-path-summary/outputs/path_{1-5}_expanded.csv`
- `03-path-summary/outputs/path_expansion_summary.json`
- `03-path-summary/figures/similarity_matrix_heatmap.png`
