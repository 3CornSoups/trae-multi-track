## 二、主路径分析算法

### 2.1 算法流程总览

```
全引文网络 (最大WCC: 208,799 节点, 1,016,581 边)
    │
    ▼
[Step 1] SPC 权重计算 (Hummon & Doreian, 1989)
    │  forward[u] = Σ forward[p]  (p ∈ u的前驱, 拓扑排序+DP)
    │  backward[v] = Σ backward[s] (s ∈ v的后继)
    │  SPC(u,v) = forward[u] × backward[v] / total_paths
    │  物理含义：经过该边的"源→汇"完整路径越多 → 边越关键
    │
    ▼
[Step 2] Key-Route 多路径提取 (Liu & Lu, 2012 改进版)
    │  ① 选 SPC 最高的 Top-30 条边作为候选种子
    │  ② 每粒种子双向贪心扩展：
    │     - 向汇扩展：从 seed_v 出发，每次选 SPC 最大的后继
    │     - 向源扩展：从 seed_u 出发，每次选 SPC 最大的前驱
    │  ③ 边惩罚：已提取路径上的边权重 ×0.001（0.1%）
    │  ④ Jaccard 多样性过滤：新路径与已有路径节点重叠 > 50% → 丢弃
    │  ⑤ 若不足5条，放松到 70% 重叠阈值补充
    │
    ▼
5条区分度主路径
```

### 2.2 SPC 权重计算细节

```
算法伪代码：
─────────────────────────────────────
输入：有向图 G(V, E)
输出：每条边的 SPC 权重

1. 找出所有源节点（入度=0）和汇节点（出度=0）
2. Kahn BFS 拓扑排序 → topo 序列
3. 正向DP（沿 topo 顺序）：
   forward[v] = Σ forward[u]  ∀u ∈ predecessors(v)
   初值：forward[源] = 1.0
4. 反向DP（沿 topo 逆序）：
   backward[u] = Σ backward[v]  ∀v ∈ successors(u)
   初值：backward[汇] = 1.0
5. SPC(u,v) = forward[u] × backward[v] / total_paths
   其中 total_paths = Σ forward[汇]
─────────────────────────────────────
```

**SPC 的物理直觉**：

```
假设有一条边 e = (u, v)，如果：
  - 有 1000 条不同的路径从源到达 u
  - 有 500 条不同的路径从 v 到达汇
  - 总源→汇路径数 = 10000

则 SPC(u,v) = 1000 × 500 / 10000 = 50

这意味着在所有源→汇路径中，平均有 50 条"必经"边 e，
反映了边 e 在技术知识流动中的枢纽地位。
```

### 2.3 Key-Route 扩展过程图解

```
从种子边 (A→B) 出发：

向后扩展（→源）          种子边        向前扩展（→汇）
  ⋯ ← D ← C ←          A → B          → E → F → G → ⋯
  (每次选入边SPC最大)                  (每次选出边SPC最大)

最终路径: D → C → A → B → E → F → G
```

### 2.4 多样性保证机制

| 机制 | 参数 | 作用 |
|------|------|------|
| 边惩罚 | 已用边权重 ×0.001 | 迫使后续路径绕开已覆盖区域 |
| Jaccard 过滤 | 重叠 > 50% 则丢弃 | 确保每条路径代表不同的技术轨道 |
| 放松机制 | 不足5条时阈值升至 70% | 平衡区分度与覆盖度 |

## 三、5条主路径的来源与结果

### 3.1 为什么是5条？

`TOP_N_PATHS = 5` 是代码中的**硬编码参数**（`extract_main_paths.py` 第270行）。

**方法论依据**：

1. **Key-Route 方法的初衷**（Liu & Lu, 2012）：单一 Global Main Path 只能捕捉"最粗"的技术主干，现实中技术演化往往呈现**多轨道并行**格局——不同技术路线（如 SSVEP 路线 vs EMG 路线 vs 可穿戴传感器路线）各自独立演化
2. **5是经验平衡点**：
   - 太少（1-2条）：遗漏重要技术分支
   - 太多（10+条）：引入噪声路径，缺乏解释力
3. **多样性约束保证了区分度**：边惩罚 + Jaccard 过滤确保5条路径节点重叠 < 50%，确实代表**不同的技术轨道**而非同一轨道的微小变体

### 3.2 5条路径的实际结果

| 路径 | 节点数 | 年份跨度 | CN节点 | 外国节点 | 总SPC权重 | 技术主题 |
|------|--------|---------|--------|---------|----------|---------|
| #1 | 23 | 1977→2025 | 13 | 10 | 1.195 | SSVEP/P300 → 康复&交互控制 |
| #2 | 22 | 1966→2024 | 10 | 12 | 0.987 | 脑机接口 → 多模态交互（无人机/HUD/VR） |
| #3 | 22 | 1975→2023 | 0 | 22 | 0.921 | 神经肌肉接口(EMG) → 手势识别 |
| #4 | 17 | 1993→2018 | 0 | 17 | 0.924 | 医疗监控 → 可穿戴传感器 |
| #5 | 14 | 1977→2025 | 0 | 14 | 0.592 | 神经接口 → 连续运动控制 |

**关键发现**：

- 路径#1 和 #2 中中国专利参与较深（56.5% 和 45.5%），但主要集中在**应用层**（康复、交互、控制）
- 路径#3、#4、#5 中**中国专利完全缺失**，全部由外国（主要是美国）专利主导
- 共享枢纽节点 `US-2003093129-A1`（闭环脑机接口，2001年）出现在所有5条路径中，是美国的核心底层专利

## 四、⚠️ 时间切片问题（重要）

### 4.1 你期望的时间窗口

> 2000-2005, 2000-2010, 2000-2015, 2000-2020, 2000-2026

### 4.2 当前代码的实际行为

**当前代码没有实现任何时间切片**。代码对整个数据集（1966-2025年所有专利）**一次性**运行 SPC + Key-Route：

```python
# extract_main_paths.py 的实际逻辑
G = G_full.subgraph(largest_wcc).copy()   # 全时段网络
edge_spc, ... = compute_spc(G)             # 一次性SPC
main_paths = key_route_search(...)         # 一次性提取5条
```

这意味着：
- 提取出的5条路径横跨 1966-2025，是**整个技术史的静态快照**
- 无法观察技术轨道如何随时间"生长"和分叉
- 无法回答"2010年之前的技术轨道是什么样的？"

### 4.3 要实现滑动窗口，需要修改

如果要实现你期望的时间切片分析，需要做 **sliding-window main path analysis**：

```
算法思路（需要新增代码实现）：
─────────────────────────────────────
时间窗口: [2000, 2005], [2000, 2010], [2000, 2015], [2000, 2020], [2000, 2026]

对每个窗口 [2000, YYYY]：
  1. 过滤网络 G_filtered = G中所有 app_year ≤ YYYY 的节点及其边
  2. 提取 G_filtered 的最大弱连通分量
  3. 重新计算 SPC 权重（因为网络结构变了）
  4. 重新运行 Key-Route 提取主路径（路径数可为1-3条）
  5. 记录每条路径的节点序列、年份跨度、中外比例

预期输出：
  窗口         主路径                    年份跨度    CN占比
  ─────────────────────────────────────────────────────
  2000-2005    路径A (神经信号基础)     1977-2005     0%
  2000-2010    路径B (BCI范式形成)      1977-2010     5%
  2000-2015    路径C (BCI应用拓展)      1977-2015    20%
  2000-2020    路径D (多模态+穿戴)      1977-2020    35%
  2000-2026    路径E (完整轨道)         1977-2025    40%
```

**关键差异**：每个窗口的 SPC 权重分布不同——随着更多后期专利加入网络，一些边的重要性会上升，另一些会下降，路径结构也会随之变化。这就是技术轨道"演化"的定量证据。

## 五、路径拓展：知识图谱 + 风险指数

### 5.1 知识图谱构建（实验3：`exp3_knowledge_graph.py`）

主路径只告诉我们"哪些专利在技术轨道上"，但不揭示"这些专利在做什么"——知识图谱填补这个语义空白。

#### 方法

**使用 DeepSeek V4 Flash API（LLM）进行实体关系抽取**：

```
输入：主路径上的专利（标题 + IPC/CPC + 摘要）
  │
  ▼
DeepSeek V4 Flash
  │  System Prompt: "你是脑机接口领域的技术情报分析专家..."
  │  要求输出 JSON 格式的实体和关系
  │
  ▼
结构化知识图谱
```

#### 实体类型定义

| 实体类型 | 说明 | 示例 |
|---------|------|------|
| `TECHNICAL_FUNCTION` | 技术功能 | "运动想象识别""情绪状态检测""神经信号解码" |
| `TECHNICAL_PRINCIPLE` | 技术原理/方法 | "深度学习CNN""SSVEP""fNIRS" |
| `KEY_COMPONENT` | 关键部件/材料 | "干电极""柔性电路""脑电采集芯片" |
| `APPLICATION_SCENARIO` | 应用场景 | "医疗康复""人机交互""疲劳监测" |
| `IPC_CLASS` | IPC分类号 | A61B（医学诊断）、G06F（数字处理） |

#### 关系类型

```
专利 ──implements──→ 技术功能      （"实现某功能"）
专利 ──adopts──────→ 技术原理      （"采用某原理"）
专利 ──contains────→ 关键部件      （"包含某部件"）
专利 ──applied_in──→ 应用场景      （"应用于某场景"）
专利 ──classified_as→ IPC分类      （"分入某IPC"）
专利 ──cites───────→ 被引专利      （引用关系）
专利 ──belongs_to_country→ 国家    （国别归属）
```

#### 实体去重策略

按 `(实体类型, 实体名称)` 键去重——确保"SSVEP"在不同专利中被识别为同一个技术原理实体，而非重复创建。

#### 双时态对比

以 **2015年** 为分界点（中国专利在 BCI 领域开始密集出现的时间拐点），分别构建：

- **早期知识图谱**（< 2015年）：反映外国主导时期的技术结构
- **后期知识图谱**（≥ 2015年）：反映中国进入后的技术生态变迁

通过对比两个时期的实体类型分布差异，可以识别技术焦点的转移方向。

### 5.2 技术替代风险指数（实验4：`exp4_risk_index.py`）

在知识图谱和主路径分析基础上，设计**三层指标体系**量化技术替代风险。

#### 指标体系

```
综合替代风险指数 (Composite Risk Index)
  = w_A × A + w_B × B + w_C × C
  （默认等权重 w_A = w_B = w_C = 1/3）
          │
  ┌───────┼────────┬──────────────┐
  ▼       ▼        ▼              ▼
  A. 外国技术      B. 中国技术     C. 技术替代
     控制力           边缘化程度       倾向
     (越高→风险越大)  (越高→风险越大)  (越高→风险越大)
```

#### A. 外国技术控制力（Foreign Control）

| 子指标 | 计算方式 | 含义 |
|--------|---------|------|
| A1 核心专利占比 | 外国专利数 / 主路径总专利数 | 外国在核心技术轨道上的占位程度 |
| A2 平均自引率 | 外国专利引用外国专利的比例 | 外国技术体系的内部闭环程度 |
| A3 IPC覆盖广度 | 外国专利涉及的不同IPC大类数 | 外国技术的横向覆盖范围 |

#### B. 中国技术边缘化程度（CN Marginalization）

| 子指标 | 计算方式 | 含义 |
|--------|---------|------|
| B1 主路径偏离度 | CN主路径与Global主路径的重合度的倒数 | 中国技术轨道偏离全球主流的程度 |
| B2 引用衰减率 | CN专利被后续专利引用的衰减速度 | 中国专利的知识影响力持续性 |
| B3 PageRank百分位 | CN节点在主路径PageRank中的排名 | 中国专利在网络中的结构重要性 |

#### C. 技术替代倾向（Substitution Tendency）

| 子指标 | 计算方式 | 含义 |
|--------|---------|------|
| C1 功能-原理替代对 | 知识图谱中"同功能不同原理"的实体对数量 | 新技术原理替代旧原理的活跃程度 |
| C2 外国路线增速 | 外国新专利增长 vs 中国新专利增长 | 外国技术路线的扩张速度优势 |
| C3 跨界引用方向 | Foreign→CN引用 vs CN→Foreign引用 | 技术知识的流向不对称性 |

#### 综合指数解读

| 风险等级 | 指数区间 | 含义 |
|---------|---------|------|
| 低风险 | 0.0-0.3 | 中国技术与全球主流轨道对齐，替代压力小 |
| 中风险 | 0.3-0.6 | 存在局部边缘化或替代倾向 |
| 高风险 | 0.6-1.0 | 多维度风险叠加，技术替代压力显著 |

## 六、核心发现与改进建议

### 6.1 方法论优势

- **SPC + Key-Route 是引用最多的主路径分析方法**（Hummon & Doreian 1989 被引 >2000次，Liu & Lu 2012 被引 >500次），方法论根基扎实
- **边惩罚 + Jaccard 多样性过滤**确保了多路径的区分度，避免提取出高度重叠的"伪不同"路径
- **LLM 驱动的知识图谱**将纯结构分析（引文网络）拓展到语义分析，创新性较强
- **三层风险指标体系**有明确的理论框架（控制力-边缘化-替代倾向三维度）

### 6.2 需要关注的问题

| 问题 | 严重程度 | 建议 |
|------|---------|------|
| **未实现时间切片** | 🔴 高 | 论文框架中提到 2000-2005/2010/2015/2020/2026 五个时间段，但代码没有实现。需要新增 sliding-window 逻辑 |
| **路径数硬编码为5** | 🟡 中 | 建议在论文中解释选择5条的方法论依据，也可考虑用肘部法则（elbow method）数据驱动确定 |
| **全引文网络缺少可视化** | 🟡 中 | 建议至少用 Gephi 出一张全网络布局图作为论文的 overview figure |
| **LLM抽取的一致性问题** | 🟡 中 | DeepSeek API 对同一专利的多次抽取可能产生不一致结果，建议报告 inter-rater reliability |
| **风险指数权重缺乏校准** | 🟢 低 | 默认等权重是合理的初始选择，建议在论文中说明权重可做敏感性分析 |
