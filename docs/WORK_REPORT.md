## 一、问题诊断

### 问题1: 引文网络"链接稀疏、线条很少"

**不是bug, 是专利引文网络的固有特征。**

| 指标 | 数值 |
|------|------|
| 网络节点 | 343,374 |
| 网络边数 | 1,191,230 |
| 密度 | 1.01 × 10⁻⁵ |
| 平均出度 | 3.47 |

每个专利平均只引用3.5个其他专利 — 这是专利引用行为的常态, 不是数据质量问题。

**真正的问题在可视化**: 旧代码画了全部120万条边, 每条边透明度alpha=0.15, 结果就是什么都看不清。

**解决方案**: 不画全网络, 只画主路径子图 (93条高SPC权重的核心边), 结构立刻清晰。

---

### 问题2: 主路径提取算法缺陷

#### 旧算法 (3个致命问题)

| 问题 | 表现 | 原因 |
|------|------|------|
| **1. 路径过短** | 全局主路径仅6个节点 | Dijkstra `-log(SPC)`天然惩罚长路径 |
| **2. 路径重复** | 所有种子走向同一走廊 | Key-Route贪心无多样性约束 |
| **3. 无区分度** | 输出全是US专利, 看不到多条并行轨道 | 旧代码只做单轮Key-Route, 无边惩罚 |

#### 旧算法的Dijkstra陷阱

```
cost(edge) = -log(SPC)
path_cost  = Σ -log(SPC_i) = -log(Π SPC_i)

→ 每条边增加正成本 → 算法天然偏好短路径
→ 结果: 只找到6个节点的"最短路径", 跳过大部分技术演化节点
```

## 二、新算法设计

### 整体流程

```
原始专利数据
    ↓
[模块1] 引文网络构建
    ↓
citation_pairs.csv + patent_info.csv
    ↓
[模块2] SPC边权重计算 (拓扑排序+DP, O(V+E))
    ↓
Key-Route多路径提取
    ├── Top-30 SPC种子边
    ├── 双向贪心扩展 (每步选最大SPC邻边)
    ├── 边惩罚 (已用路径边 × 0.001~0.01)
    ├── Jaccard多样性过滤 (重叠 ≤ 50%)
    └── 输出Top-5区分度主路径
    ↓
可视化 + 报告
```

### SPC (Search Path Count) — Hummon & Doreian (1989)

```
正向DP:  forward[u] = Σ forward[p]  (p ∈ G.predecessors(u))
反向DP:  backward[v] = Σ backward[s] (s ∈ G.successors(v))
边权重:  SPC(u,v) = forward[u] × backward[v] / total_paths
```

高SPC = 大量源→汇路径的"必经边" = 技术演化主干

### Key-Route — Liu & Lu (2012) 改进版

原始Key-Route所有种子都向同一最高SPC边收敛。我们的改进:

1. **边惩罚**: 已提取路径上的边权重降为原来的0.1%, 迫使下条路径走不同路线
2. **多样性过滤**: 新路径与已有路径的Jaccard重叠超过50%则丢弃
3. **放松回退**: 严格过滤不够5条时, 放松到70%重叠补充

## 四、关键发现

### 1. 中国BCI专利的"应用层依赖"

中国专利集中在两条主路径 (#1和#2) 上, 且全部处于技术链的**下游应用层**:
- 康复训练系统、智能家电控制、AR交互、无人机操控
- 而上游的脑电信号处理、神经接口系统、生物传感器专利仍属外国

### 2. 三条技术轨道中国完全缺位

| 缺失轨道 | 外国主导企业/机构 | 风险 |
|---------|-----------------|------|
| EMG神经肌肉接口 | Meta(Facebook), CTRL-Labs | 下一代人机交互核心技术 |
| 可穿戴医疗传感器 | Masimo, Medtronic | 医疗级BCI硬件入口 |
| 神经接口运动控制 | Neuralink, Kernel | 侵入式/高精度脑机接口 |

### 3. 时间维度: 中国正在追赶, 但起点晚

- **2012年前**: 主路径上基本没有中国专利
- **2012-2018**: 中国开始在SSVEP/P300方向出现 (CN-102778949-A, CN-103399639-A)
- **2018-2025**: 中国专利密集出现, 覆盖康复/交互/控制方向
- 但EMG/可穿戴传感器/运动解码三条轨道至今无中国专利
