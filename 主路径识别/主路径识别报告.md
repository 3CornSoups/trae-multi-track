# 主路径识别报告

> 基于 6 个累积时间窗口的 BCI 专利引文网络，采用 **SPC + Key-Route** 方法识别技术演化主路径。
> 生成日期：2026-08-04 ｜ 全部数据文件见 `outputs/` 目录

## 一、方法说明

### 1.1 SPC 权重（Search Path Count，Hummon & Doreian 1989）

引文网络是有向无环网络：**施引专利 → 被引专利**。网络中存在大量**源点**（入度为 0 的专利）和**汇点**（出度为 0 的专利）。

对每条边 (u→v)，SPC 定义为：

```
SPC(u→v) = forward[u] × backward[v] / total_paths

  forward[u]   = 从所有源点到 u 的路径数
  backward[v]  = 从 v 到所有汇点的路径数
  total_paths  = 源点到汇点的总路径数
```

**直观含义**：SPC 衡量一条边被多少条完整的"源→汇"引文链经过。SPC 高的边是大量技术演化路径的**必经之路**，代表技术发展主干。

### 1.2 SPLC 权重（Search Path Link Count，对照指标）

```
SPLC(u→v) = forward[u] / total_paths
```

SPLC 只统计从源点出发到达 u 的路径数（不要求到达汇点），作为 SPC 的对照权重，用于交叉验证边的技术重要性。

### 1.3 Key-Route 多路径提取（Liu & Lu 2012）

主路径识别采用 **Key-Route 算法**，避免只提取单一路径（丢失技术轨道分化的信息）：

1. **种子边选择**：按 SPC 权重降序取 Top-30 条边作为候选种子
2. **双向贪心扩展**：从种子边出发，向源方向（前驱）和汇方向（后继）各扩展至多 50 步，每步选择 SPC 权重最大的边
3. **边惩罚**：已提取路径上的边权重降至 0.1%，迫使后续路径走不同路线（严格阶段）；放松阶段降至 1%
4. **Jaccard 多样性过滤**：新路径与已有路径节点重叠度 ≤ 50%（严格）/ ≤ 70%（放松）才保留
5. **路径数量不截断**：所有通过多样性过滤的路径全部输出，按总 SPC 权重降序排序

### 1.4 方法选择理由

| 方法 | 特点 | 是否采用 | 原因 |
|------|------|---------|------|
| SPC | 经典、计算高效 O(E) | ✅ | 专利引文分析标准方法，与论文引用文献一致 |
| SPLC | 与 SPC 同成本 | ✅ | 作为对照权重，增加结果稳健性 |
| SPNP | 理论最严谨但需枚举所有节点对 O(N²) | ❌ | 23 万节点网络不可行（530 亿对） |
| Key-Route | 多路径提取，识别轨道分化 | ✅ | 论文需要识别技术轨道演化 |
| 局部/全局主路径 | 只给单一路径 | ❌ | 丢失技术分化信息 |

### 1.5 环处理

引文网络理论上应无环（专利只能引用更早的专利），但数据中存在约 1.2% 的反向时间引用边（施引年 < 被引年，数据标注误差导致）。SPC 计算采用 **Kahn BFS 拓扑排序**，环中节点按剩余入度顺序追加，保证 DP 计算可完成。

### 4.2 技术轨道演化

Key-Route 提取的路径可视为**技术轨道**。跨窗口比较可观察：

1. **轨道持续**：早期窗口（pre-2000）出现的基础技术轨道，在后期窗口是否继续存在（延伸）
2. **轨道分化**：后期窗口出现的新轨道（新的高 SPC 边组合）
3. **轨道兴衰**：某窗口的路径种子边在后续窗口是否仍为高 SPC 边

> 注：由于累积窗口的网络规模逐步扩大（4.4 万 → 23.8 万节点），后期窗口的 SPC 绝对值远大于早期窗口（源→汇总路径数从 10⁸ 增长到 10¹⁵），**跨窗口比较应看路径内容而非 SPC 绝对值**。

## 五、使用说明：如何挑选主路径

每窗口的 `window_{label}_paths_all.csv` 已按**总 SPC 权重降序**排列，可直接挑选。建议挑选策略：

| 指标 | 含义 | 挑选建议 |
|------|------|---------|
| `total_spc` | 路径总 SPC 权重（主排序指标） | 权重越高 = 技术演化必经之路越核心 |
| `node_count` | 路径节点数 | 长路径覆盖更多技术节点，适合轨道演化分析 |
| `year_span` | 年份跨度（最早→最晚） | 跨度大 = 轨道延续时间长 |
| `cn_nodes` | 中国专利节点数 | 关注中国技术参与度时挑选 CN 占比高的路径 |
| `stage` | 提取阶段（strict/relaxed） | strict 更核心，relaxed 是补充 |

**推荐组合**：论文分析通常选取每窗口 Top-1~3 条（权重最高）+ 1~2 条长跨度路径（轨道演化）+ 1~2 条含 CN 节点路径（中国参与），共 3~5 条/窗口。
