# 引文网络构建

## 概述

基于 BCI 领域两个专利数据源（BCI 数据库导出 + incoPat 外部专利），完成专利数据合并、全量引文网络构建，并按 6 个累积时间窗口切分子网络，为后续主路径分析（SPC + Key-Route）和技术演化研究提供数据基础。

- **构建日期**: 2026-08-04
- **输入数据**: `bci_cleaned.xlsx` (BCI数据库, 18,651行) + `bci_external_patents_filtered.xlsx` (incoPat, 18,291行)
- **脚本位置**: `merge_patent_data.py`, `build_citation_network_full.py`, `build_citation_network_windows.py`

## 2. 全量引文网络

### 2.1 构建方法

- **节点** = 合并表中的专利（内部专利，有元数据） ∪ 引文中出现的专利（外部专利，仅公开号）
- **边** = 后向引用 (施引专利 → 被引专利) ∪ 前向引用 (被引用信息验证)，去重后合并
- **边方向约定**: source --引用--> target，入度 = 被引用次数（标准引文分析方向）
- **自引边**: 仅计数不建边
- **孤立节点**: 入度=0 且出度=0，在统计中单独报告

|------|------|

| **总边数（去重后）** | **1,159,638** |

## 3. 时间窗口引文网络

### 3.1 窗口定义与处理策略

采用**累积窗口**（每个窗口包含从最早到截止年份的所有专利），反映知识累积过程。

| 窗口 | 条件 | 对应阶段 |
|------|------|----------|
| **pre-2000** | app_year < 2000 | BCI 技术萌芽期 |
| **2000-2005** | app_year ≤ 2005 | 第一波专利浪潮 |
| **2000-2010** | app_year ≤ 2010 | 技术成长期 |
| **2000-2015** | app_year ≤ 2015 | 信号处理+电极技术爆发期 |
| **2000-2020** | app_year ≤ 2020 | 商业化加速期（Neuralink效应） |
| **2000-2026** | app_year ≤ 2026 | 当前全貌（AI+BCI融合期） |

**处理流程**:
1. 筛选窗口内内部专利 + 全部外部节点（维持连通性）
2. 删除孤立节点（入度=0 且 出度=0）
3. 取最大弱连通分量（Giant WCC）

**日期字段**: 申请日（最接近发明时间点，覆盖率 99.99%）

### 3.2 跨窗口对比

| 窗口 | 内部专利 | 外部节点 | 总节点 | 总边 | 密度 (×10⁻⁵) | Giant WCC占比 | 最大入度 |
|------|---------|---------|--------|------|-------------|-------------|---------|
| pre-2000 | 698 | 43,288 | 43,986 | 118,412 | 6.12 | 19.0% | 1,327 |
| 2000-2005 | 1,398 | 58,935 | 60,333 | 185,173 | 5.09 | 25.9% | 1,320 |
| 2000-2010 | 3,629 | 93,878 | 97,507 | 358,348 | 3.77 | 41.5% | 1,343 |
| 2000-2015 | 7,945 | 136,937 | 144,882 | 546,759 | 2.61 | 60.4% | 1,379 |
| 2000-2020 | 17,340 | 188,030 | 205,370 | 841,843 | 2.00 | 82.1% | 1,443 |
| 2000-2026 | 27,468 | 210,460 | 237,928 | 1,008,117 | 1.78 | 90.7% | 1,488 |

### 3.3 窗口增长分析

```
pre-2000        :  43,986 节点,  118,412 边 (初始窗口)
2000-2005       : +16,347 节点,  +66,761 边 (+37.2%)
2000-2010       : +37,174 节点, +173,175 边 (+61.6%)  ← 增长最快
2000-2015       : +47,375 节点, +188,411 边 (+48.6%)
2000-2020       : +60,488 节点, +295,084 边 (+41.7%)  ← 增量最大
2000-2026       : +32,558 节点, +166,274 边 (+15.9%)
```

### 3.4 关键发现

1. **2010-2015 是 BCI 技术的"爆发窗口"**：节点增长 61.6%、边增长近 100%，恰好是 Neuralink 成立（2016）前夕，电极阵列、信号解码算法等基础设施专利大量涌现。

2. **密度递减是健康的信号**：密度从 6.12×10⁻⁵ 降至 1.78×10⁻⁵——新专利在拓展开辟新的引用分支，而非反复引用同一批旧专利，说明技术领域在持续向外扩张而非内卷。

3. **Giant WCC 占比从 19.0% → 90.7%**：随着 BCI 专利增多，原本孤立的引用链条被串联成巨型连通分量。pre-2000 窗口的外部节点大多是"休眠"的基础专利（如神经科学、材料科学），直到 2010 年后才被 BCI 专利引用而进入核心网络。

4. **2020-2026 窗口增速放缓至 15.9%**：该窗口已接近全量网络（占总节点 90.7%），增长空间自然收窄；同时也反映了近期专利申请到公开的 18 个月滞后效应——2025-2026 年的专利可能尚未全部公开。

5. **外部节点的"胶水效应"**：87.9% 的节点是外部专利（无元数据），它们充当了引文链中的桥接者。删除它们会导致网络碎片化——这也解释了为什么每个窗口都要保留全部外部节点。

## 5. 技术选型说明

| 选型 | 决定 | 理由 |
|------|------|------|
| 窗口模式 | 累积窗口 | 保证 DAG 完整性，反映知识累积 |
| 起始点 | 统一 2000 年起 | 对齐现有论文分析框架 |
| 间隔 | 5 年 | BCI 领域技术迭代节奏 |
| 日期字段 | 申请日 | 最接近发明时间，覆盖率 99.99% |
| 公开号规范化 | 去连字符 + US 前导零补齐 | 消除同一专利的多种写法 |
| 外部节点处理 | 全部保留 | 维持网络连通性 |
| 边方向 | source → target = 施引 → 被引 | 入度 = 被引次数（标准引文分析方向） |
